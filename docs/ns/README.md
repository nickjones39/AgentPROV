# AgentPROV namespace and persistent identifiers

- Vocabulary namespace: `https://w3id.org/agentprov/ns#` (prefix `apv:`). Current version: **apv 0.2.0**
  (`owl:versionIRI` `https://w3id.org/agentprov/ns/0.2.0`; minor, additive over 0.1.0: D-500, D-501).
  `apv-0.2.ttl` here is a byte copy of `src/agentprov/vocab/apv-0.2.ttl`, kept in sync by `tools/sync_ns.py`
  (`--check` in tests). `apv-0.1.ttl` is the published apv 0.1.0 release, kept unchanged.
- Execution instance IRIs: `https://w3id.org/agentprov/exec/<execution-id>#<local-id>`. These are
  identifiers and are not individually dereferenceable.
- Target: the public repo [`nickjones39/agentprov-ns`](https://github.com/nickjones39/agentprov-ns), served by
  GitHub Pages at <https://nickjones39.github.io/agentprov-ns/>. apv 0.1.0 was published there on 2026-10-08
  (commit `8ac6511`): `ns/apv.ttl` and `ns/index.html` hold the current version, and `ns/0.1.0/` the versioned copy.
  apv 0.2.0 was published there on 2026-10-22 (UTC; commit `7ee2fde`, with the user's go): `ns/apv.ttl` and
  `ns/index.html` now hold 0.2.0, and `ns/0.2.0/` the versioned copy. The w3id redirects for `/ns/0.2.0` answered 303
  as for 0.1.0, and the served Turtle files matched the local ones byte for byte (sha256 `2c6407d1…ca5e`).
  The HTML page is generated by `tools/ns_page.py`.
- Redirects: `perma-id/w3id.org` → `ids/agentprov/.htaccess`, pull request #6836 (opened 2026-10-07, merged 2026-10-09; the redirects resolve (checked 2026-10-11: `/ns` and `/ns/0.1.0` answer 303 to `apv.ttl` for `text/turtle` and to the HTML page otherwise)). On 2026-10-08 the versioned `/ns/<x.y.z>` content-negotiation rules were added to that same PR, rather than
  to a second PR that would depend on it.

To publish a new vocabulary version `x.y.z`: copy the TTL to `agentprov-ns` as `ns/apv.ttl` and `ns/x.y.z/apv.ttl`,
render `ns/index.html` and `ns/x.y.z/index.html` with `tools/ns_page.py`, and never change an already published
`ns/<version>/`. The w3id rules need no change for new versions.

Do not deposit corpora that carry these IRIs until the w3id PR has been merged and resolves (DECISIONS
Addendum D-3).
