- **D-92 (2026-10-11, phase 10c: a model is asserted only where a document states which model produced the runs;
  user decision).** When no log field names the model, an identity-table row (class I, as for AgentDyn's pipeline
  directories) may cite a README or paper that states the model of these runs (kongminOS: DeepSeek V4-Flash). A code
  default is not such a statement: Wakeful-Cloud/llm-lock (53,307 runs, `pipeline_name` `local`) is sealed with
  `unk {"/model": "not_recorded"}` (A-3) and its `agentdojo/main.py` default goes into `ext` as a note only; the same for
  SENTRY's 72 OpenRouter free-router runs. Model-level analyses exclude such runs and the datasheet says so.
  - **Why:** a default the run environment may override is a guess (invariant 2); a wrong model on 53,307 runs would
    distort every per-model figure.
  - **Rejected:** asserting the code default at class I (no evidence links it to these runs).
