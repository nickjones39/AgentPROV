  - **D-667 Judges and cost.** Judge roles, models and endpoints are explicit in the plan and in the consent. A sample
    count, `message_limit` and `token_limit` are mandatory. Estimates come from stored priors (survey AgentHarm,
    per sample: about 4.4k input and 1.0k output agent tokens, about 1.5 judge calls). The first real call is a
    separate 4-sample probe (agent and judge gpt-4o-mini, capped at $0.50), which needs its own typed yes.

    With D-725 (train 2, 2026-10-22): the API call and cost caps reserve a per-cell worst case that is the AgentDojo
    cell's (`policy.CELL_CALL_BOUND`, 48 calls). An Inspect cell makes up to samples x epochs x `message_limit` agent
    calls plus its judges' calls, for which no bound is decided yet, so the caps could not hold. A real run of an
    Inspect backend with caps active (always, for an API endpoint) is therefore refused (`cli.refused.api_caps`,
    exit 4; `cli/run.py` `_refuse_unbounded_caps`). Scripted runs are unaffected. Superseded the same day by D-740,
    the per-cell Inspect bound (user-approved option (a)). It refuses only what it cannot bound, and it carries the
    probe's parameters.
