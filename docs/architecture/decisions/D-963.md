- **D-963 (2026-10-29, an e-mail address withholds executions only through their own records; user-approved
  2026-10-29 in the wave-2 pre-release-checks session ("Own records only"); byte class 0).** In the wave-2 seal dry run
  of `memo-ozdincer-agentdojo` (dialect `agentdojo.results_container`: one results file holds many executions), 6
  executions hold a model-written address at a public mail provider (D-810 class `withhold`). D-810's `address` rule hit
  their 5 shared results files at scope `executions` and withheld every execution citing them: 425 of 13,070 (51 tasks).
  The origins pass had predicted it (`executions_via_shared_objects`); round 1 never met it, since every round-1 corpus
  stores one file per execution.
  - **Decision.** A raw object an `address` rule hits is withheld alone, for either persona class; an execution is
    withheld only when its own derived records hold a listed address (the derived-file hit, which also withholds its
    primary object). This is how D-235 treats a derived hit and D-311 an issue rule: the other executions that cite the
    object stay released, and `chain` counts the object as `raw_withheld` for them. D-961 (a `withhold-object` address
    withholds its object alone) is the special case of this rule for that class. The rule's recorded id, kind and scope
    (`email-withheld`, `address`, `executions`) do not change; the backstops are unchanged, so no released file holds a
    listed address.
  - **Effect.** `memo-ozdincer-agentdojo`: 6 executions withheld instead of 425; the 5 results files are withheld as
    objects. No other wave-2 corpus has a shared object that holds a `withhold` address (the origins pass,
    `executions_via_shared_objects` equals `executions` everywhere else).
  - **Bytes (class 0).** `corpus/withhold.py` is in no stage scope. Round 1: each of the 187 executions its seals
    withheld through `email-withheld` holds a `withhold`-class digest in its own AER (checked in the `.withheld`
    sidecars), so the plans are unchanged. Tests: a shared raw object withholds only the execution whose record holds
    the address (fails without the fix); a container hit alone withholds no execution, and an execution whose own
    record holds the address is withheld with its primary.
  - **Rejected.** Keeping the 425 (D-810 as built): it withholds 419 executions whose records hold no listed address,
    for the bytes of a file they share; the file is withheld anyway.
