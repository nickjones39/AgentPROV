- **D-22 (2026-10-11, no scheduled CI; network-rebuilding jobs by manual dispatch at release, deposit and submission
  points; user decision).** AgentPROV has no scheduled or nightly CI of any kind. The feature is removed from the
  architecture, not deferred. Push and pull-request CI is unchanged. The jobs that rebuild pinned environments from the
  network, or run the slow gates (`backend-autodojo`, `old-vs-new`, `network` and `thorough`; the latter two are built
  when their gates have tests), run by `workflow_dispatch` only. K.19.1 defines the points at which they are
  dispatched: before tagging a software release; before building or depositing a corpus release (depositing also needs
  the user's explicit instruction, D-5); before submitting a thesis chapter or paper that reports live-backend or
  migration results; and after changing what they exercise (`backends/**`, `capture/**`, a backend `uv.lock`, the
  baseline lock in `migration/`, the gate-C6 register, the `agentdojo` capture mapping). The supply-chain workflow runs
  on changes to any `uv.lock` and by manual dispatch. The Hypothesis `nightly` profile (K.3.4) is renamed `thorough`:
  an on-demand profile run locally or by dispatch, with no code yet.
  - **Why:** this is a single-researcher project and external pins rarely change. What matters is that the pinned
    environments rebuild at the points where the work claims they can, and a failure there (fork rewritten, wheel
    yanked, file moved) is then reported as a finding, not re-pinned silently.
  - **Rejected:**
    - a nightly schedule: it re-ran the full four-OS matrix every night and duplicated push CI, at the cost of GitHub
      Actions minutes on a private repository;
    - a weekly schedule: the same duplication at a lower rate.
  - **Supersedes:** the schedule trigger, the "nightly" columns and profile, and the "weekly" supply-chain run of K.3.4,
    K.3.5, K.18.1 and K.19; K.20 item 1; MN M.7 and N.2.14; G.7.2 and G.10 (SEC-23); and the "optional nightly" gate C1
    of J.2.6, J.3.4 and J.8 (RM-22).
