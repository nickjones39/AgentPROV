- **D-443 (2026-10-14, GUI visual system; user decision 2026-10-14: approved as direction).**
  - **Fonts:** system fonts only. SF Pro and SF Mono are used only through the system and never bundled (Apple font
    licence); Segoe UI Variable on Windows; Adwaita Sans, Cantarell or Noto Sans on Linux.
  - **Colour:** `QPalette` roles including Accent. Status tokens carry Light, Dark and Increase Contrast values, read
    from `NSColor` system colours on macOS.
  - **Status:** always a shape plus a word.
  - **Layout:** a 4-pt grid with the metrics of macos-design §4.3.
  - **Icons:** SF Symbols through `QIcon.fromTheme` on macOS (52 names checked present); Phosphor (MIT) bundled for
    Windows and Linux.
  - **Motion:** Reduce Motion honoured (Qt 6.12 `motionPreference`).
  - **App icon:** layered (Icon Composer), with no text and no SF Symbols.
  - **Rejected:** bundling SF fonts or exporting SF Symbols (licence); Segoe Fluent Icons off Windows (licence); Fluent
    UI System Icons everywhere (a Windows look on GNOME); Remix Icon (custom 2026 licence); colour-only status.
