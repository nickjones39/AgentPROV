- **D-934 (2026-10-28, DTap: a string over 1 MiB is not inlined; catalogue `dtap` v3, semantics `dtap.tools@3`, profile
  `dtap-bench` v3; user-approved 2026-10-28 in the wave-2 session, "Fix and re-import"; byte class 1).** The wave-2
  DTap import sealed one execution (openaisdk / gpt-oss-120b, os-filesystem) as `map.adapter_defect`: its tool result at
  `m103 /parts/0/text` is a 1,715,572-byte string, and the aer/0.2 writer refuses an inline string over 1 MiB
  (`aer.string.inline_limit`, AER-V01, C.2.1(6)). The DTap mapper had no not-inlined path (F-13; Inspect had item 28 and
  D-832, OpenHands its own rule).
  - **Decision.** After the D-607 redaction pass, the mapper replaces every string whose UTF-8 encoding exceeds 1 MiB
    with `{"not_inlined": {sha256, bytes}}` of its UTF-8 bytes. A tool result's text becomes the part's `value`; a user
    or agent text part becomes an `other` part of type `text` (a typed string field cannot hold the digest). Each such
    pointer is DERIVED under the new rule `dtap.content_not_inlined@1`, and one info issue `dtap.content_not_inlined`
    names the records. The string stays in the raw artefact the record's locator names. Strings up to 1 MiB are
    unchanged. The re-mapped trajectory now seals.
  - **Versions (D-31).** The new rule mints catalogue `dtap` v3; v2, which the wave-2 tree `dtap-bench-w2` records, is
    archived byte-exact. The SEM profile `dtap.tools@3` is `@2`'s tables on catalogue v3 (one catalogue version per
    corpus, H.2.5; the D-607 pattern); `@2` stays. The source profile `dtap-bench` v3 names `dtap.tools@3` and, for
    D-935, `[import] prov_rss_bytes = 16 GiB`; v2 is archived.
  - **Bytes (class 1).** The dtap catalogue, mapper, SEM and profile digests move, so every DTap execution's AER, SEM and
    PROV header records change, and only the executions holding such a string change in content (one in DTap). The
    existing tree cannot take a retry of its failed executions without mixing versions (D-430), so DTap is re-imported
    once as a new tree at the building commit that holds D-930..D-935.
  - **Rejected.** Raising the AER inline limit (C.2.1(6) is the format's rule); withholding the execution (the data is
    valid); truncating the string (it would invent a value).
