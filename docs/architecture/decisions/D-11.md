- **D-11 (2026-10-08, artefact controls for live capture; user requirement, architect ruling).** The 13 artefact
  classes of the AgentDojo-PROV generated corpus are addressed in D.10.9.
  - **Principle:** never alter an execution to hide an artefact. Harness causes are removed by construction.
    Known-bad configurations are refused by **preflight probes** (parameter transmission, structured tool calls,
    accepted roles, server reachability). A **canary** of 10 cells, on by default, stops a misconfigured campaign
    early. What still occurs is flagged with evidence-class-I notes and seal issues, live and in a capture-quality
    report.
  - **New choices:** `--temperature-policy as-benchmark|inject` is required when a configured parameter would not be
    transmitted. `--allow-text-tool-calls` is required to run an endpoint that returns text-encoded tool calls.
  - **Kept deferred:** the replay-based cell probes for benchmark-validity defects (A13; AD-10 as ruled), pending the
    user's decision.
  - **Rejected:**
    - silent fixes, such as re-sending temperature or resampling text tool calls: they are observer effects of
      exactly the kind the baseline's `_CompatLLM` introduced;
    - discarding artefact traces: that is the selection artefact A11.
