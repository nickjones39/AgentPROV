- **D-397 (2026-10-14, core allowlist + GUI: graph view; approved as direction 2026-10-14 by the user, relayed by the orchestrator session; build after the regeneration round).**
  - **Pipeline:**
    1. `render.graph.build_model`;
    2. DOT from `render.style` with the trusted-grammar default labels only;
    3. `dot -Tjson` under the G.8.6 process controls (**core: add `json` to `render.dot.run_dot`'s formats**) for the
       core bundle and small graphs (≤ 600 nodes or 1,500 edges; edge labels never sent to `dot`);
    4. above that, a deterministic GUI-side layered layout (cycle-breaking, longest-path ranks, barycentre sweeps):
       10 ms for the largest real all-bundle document, where `dot` needed ≥ 121 s of CPU;
    5. native `QGraphicsView` drawing with built-in C++ items and a static BSP index.
  - **Rendering:** LOD tiers, an overview raster for zoomed-out views, a collapsed view of mentions and passes, and a
    digest-keyed layout cache.
  - **"All" mode:** the core layout plus overlays (inference edges, assessment badges), or engine (b) for a full
    layout.
  - **Popover:** a plain-text attribute table, not a `QToolTip`.
  - **Rejected:**
    - SVG display (no per-element interaction; an SVG web view breaks the hard constraint);
    - `prov.dot` (it emits `URL` and `href` from data);
    - in-process Python layout;
    - force-directed layout by default (it ignores PROV time direction).
