- **D-657 (2026-10-22, G5 signing; user decision relayed by the orchestrator).**
  - No Apple Developer ID will be bought, so Developer ID signing and notarisation are dropped from G5. The macOS
    bundle stays **signed ad hoc**.
  - **G5 exit criterion (macOS):** the ad-hoc-signed bundle starts on this Mac. On another Mac, the first launch
    needs Finder's right-click › Open (Gatekeeper); the README says so.
  - `gui/tools/build_bundle.py` signs nothing beyond ad hoc unless `--sign-identity NAME` is given (then that identity
    with the hardened runtime and a timestamp), so a real identity can be added later at no cost.
  - **Unchanged:** PySide6 6.12.1 when it reaches PyPI; Windows and Linux bundles on their own build hosts.
  - **Rejected:** a self-signed certificate (Gatekeeper treats it like ad hoc, and the trust step adds work); the Mac
    App Store (the sandbox blocks the checkout CLI, design §13).
