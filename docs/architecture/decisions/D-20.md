- **D-20 (2026-10-08, a worker-reported digest that does not verify is a register row; implementation ruling, phase
  8).** D.11.3 rule 2 asks for the AER seal issue `capture_error` when an artefact hash in `cell_done` does not verify.
  T0 instead stores the files under their actual digests and writes register row `map.capture_error` naming the label.
  The mapper still raises `capture_unsealed` and `capture_error` for what it can check in the evidence itself: the
  chain, a native log missing from the session (blobs and the native log are looked up by the digest the log
  records), and an unreadable pass dump. A referenced request or response blob missing from the session is not yet
  a seal issue: the call keeps its blob reference and loses only the checks that read it (sent transforms, alignment
  without `input_at`). This is an open item (AGENTS.md §0).
  - **Why:** the mismatch is a fact about the worker's report on the protocol channel, which never enters raw
    evidence, so the mapper cannot observe it. The register is where T0's ingestion facts live (HL H.6).
  - **Rejected:** passing T0's verdict into the mapper as an extra input (mapping would then depend on something
    outside the raw evidence, against invariant 6); a new catalogue rule for an issue the AER cannot justify.
