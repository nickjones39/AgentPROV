- **D-48 (2026-10-11, `agentprov stats` and `agentprov.api` design choices; phase 11).**
  - **One streamed pass per corpus, never pooled.** `stats.compute(corpora, tables)` opens each corpus with `CorpusReader`
    (read-only), streams the index once and reads an AER or PROV file only when a table needs it. Single process (N.2.12
    asks for no `--jobs`). An unreadable file is a counted per-execution failure (exit 1), never a silent skip; output
    carries no path and no clock. A sealed corpus runs the H.5.5 `checksums` level (a failing corpus gets no tables and
    exits 1); a working tree is `verification: "not_sealed"` with a notice. The report carries `fn_digest` and
    `field_groups_sha256`. The grouping key is `(source_id, profile)`: counts may be aggregated, rates never (O.3.5).
  - **Tables.** `counts` (status, unit, `execution_observed`, completeness, `n_executions` = agent executions observed,
    `n_outcome_only`, PROV output, rate exclusions, registry parts and import status, register entries); `statements`
    recounted from the stored PROV-JSON (an entry carrying `apv:evidenceClass`; bundle kinds from the E.4.2 bundle IRI;
    unclassified entries in `statements_structural`; an unknown rule is counted and a failure; `--per-execution` adds the
    O.3.5 frame, which sums to the aggregate); `unknowns` per occurrence source; `field_groups` from
    `stats/field_groups.toml`, the data form of C.3.16 (coverage `(O + D) / (cells − not_applicable)`, observed share, an
    `undeclared` count for absences without an `unk`, `message_roles` mapping `agent` to `assistant` as data).
  - **Rate exclusions are family data, never code** (D.16.17 item 4): read from `adapters/<family>/rates.toml` as package
    data without importing an adapter module; `stats` holds no source name (a test scans for every registered source id).
    No family ships one yet (DTap adds its own).
  - **Output.** JSON (JCS + LF, schema-checked in tests), text, Markdown, CSV (formula guard); data-derived labels pass
    `escape_untrusted`. `--corpus` repeatable, `--tables`, `--artefacts` (`agentprov.artefacts.scan` per execution),
    `--per-execution`, `--prov-spec`, `--select`, `--format`, `--out` (atomic, refused inside any corpus, G8).
  - **`agentprov.api`** (M.6) re-exports the stats objects; deviations are in its docstring (`read_aer(row, corpus=...)`,
    `rows(corpus, "lineage")`, `check_claim`, `coverage_phrase` and `lint_text` delegating to the claims library, D-36).
  - **Smoke** (`docs/reports/phase11/stats-smoke.md`): AgentHarm (1,056) 15.9 s base and 18.7 s with `--artefacts
    --per-execution`; Mandate (396) 3.7 s and 5.1 s; outputs byte-identical across runs; the working corpora unchanged
    (`fs_guard`).
  - **Why:** recounting from stored files is what K.5.11 item 2 asks for (an independent recount); the weakest-input and
    declared/undeclared distinctions keep the information-loss figure honest.
  - **Rejected:** reading the engine's report (not stored in a corpus); hard-coded exclusions; extending the artefact or
    rule catalogue schema with exclusion keys (owned elsewhere); counting executions without a cell in the coverage
    denominator; pooling across corpora or profiles; `--jobs`.
