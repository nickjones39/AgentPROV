- **D-26 (2026-10-11, phase 10b: DTap-Bench is added as a new adapter family before phase 11; user decision).** The
  systematic search found DTap-Bench (`AI-Secure/DTap-Bench-Agent-Trajectories` @ `836caf2f…`, Apache-2.0): 67,808
  trajectory files, 65,902 judge results and 6,682 task configurations over 10 agent-framework/model pairs, covering
  four agent frameworks (OpenAI Agents SDK, Claude Agent SDK, Google ADK, OpenClaw), 14 domains, and direct and
  indirect injection. (Full census of 2026-10-11, `dtap-bench.md` §6; the first listing counted only the 64,110
  timestamp-named trajectory files.) It is the only large, licensed, non-AgentDojo agent-security source found.
  Phase 10b adds a `dtap` adapter family in four steps: verification and source card; spec (new D section, I_matrix
  card); implementation; then the full import and its reports. Task configurations come from
  `AI-Secure/DecodingTrust-Agent-Platform` @ `a3edc9b7…` (Apache-2.0) and are joined per run. The join is verified by
  task id, instruction and malicious goal, and a mismatch is disclosed.
  - **Limitation (manuscript):** tool-description (and skill or prompt) injections are often not observable in DTap's
    run logs, which record tool descriptions and system prompts only for some harnesses (OpenClaw tool lists, debug
    logs). For 3,533 of 6,162 successful indirect attacks (57.3%) the payload appears neither in a tool output nor in
    a logged tool description. Payloads are recovered from the pinned task configuration, and exposure to them is
    recorded as a class-I inference, never as an observation (`docs/reports/systematic-search/candidates/dtap-bench.md`
    §6, which corrects §4's two-run sample).
  - **Why before phase 11:** phases 11–15 add no sources. The new family's catalogue is embedded only in the PROV of
    executions that declare it (`prov/rules/top.py:129-137`), so no existing corpus digest changes and the
    regeneration batch is unaffected. Phases 11–13 (datasheet, licence-class packaging, fuzzing, full regression) and
    the manuscript then cover it.
