  inside the try, one frame per level) and the int/dict subclass tests (B1/B2) added).** The corpus reader makes the

  - **JCS fast path:** `io.canonical.jcs_bytes` encodes a *plain* value with the stdlib `json` encoder
    (`ensure_ascii=False`, sorted keys, compact separators), which writes RFC 8785's bytes on that domain. A plain value
    is made only of exact `dict`, `list`, `str`, `int`, `bool` and `None`, with integers within ±(2⁵³−1), keys without an
    astral character (UTF-16 order is then code-point order) and depth at most 128.
  - **Fallback:** every other value, including floats, subclasses, tuples and cycles, and every error, including lone
    surrogates, goes to `rfc8785.dumps` as before. `rfc8785` stays the reference.
  - **Smaller changes:** `ingest.loaders` shares one default `IngestLimits` instead of building one per call. A register
    entry's `rid` is computed once (it was computed 5 times per entry), and its canonical bytes once per entry when the
    register is collapsed and sorted.

  - **Identity:** the same bytes everywhere. The evidence is a differential sweep of 466,848 stored documents in 8
    corpora, an exhaustive code-point test, Hypothesis differentials and scratch-import byte-diffs. None of the four
