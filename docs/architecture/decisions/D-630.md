- **D-630 (2026-10-22, pre-round review area D, the ingest/io trust boundary; integration-fix-ultra-io; user decision
  2026-10-22: approved as built, relayed by the orchestrator session; regen-batch item 161).** Thirteen fixes from `docs/reports/pre-round-review/def-review.md`. Every guard keeps or
  tightens its bound; none is relaxed except the request limit in #11, which the parent now checks.
  - **#0, the JSON stream scanner:** pass 1 refuses envelope depth over `max_json_depth` and a repeated declared
    array (`ingest.json.duplicate_key`; a path through objects only names one place) when it meets them. Before, it
    held one frame or segment for each and the envelope parse refused them later.
  - **#1, non-finite ratios:** a nested `max_ratio` and the global `max_ratio` must be finite. NaN and inf passed the
    bound checks and opened the gate.
  - **#2, multi-disk zips:** the classic EOCD's disk fields, the ZIP64 record's disk fields and a member's disk number
    refuse a multi-disk zip (G.3.5, D-243).
  - **#3, recorded deviation:** a UTF-8-flagged undecodable name refuses the whole archive, with a reason naming the
    defect. `zipfile` decodes names at open, before the member gate, and a per-member rejection would need a rewritten
    central-directory view inside T1. This is recorded in G.3.5.
  - **#4, base-60 ints:** a YAML base-60 int scalar over 4,300 characters is a `YAMLError`. Its construction is
    quadratic.
  - **#6, breaking a stale lock:** a breaker takes the `<lock>.break` token with `O_EXCL`, then unlinks the lock only
    while the same dead record is there. A left token refuses the lock and names itself. `corpus/layout.py` treats
    `.agentprov.lock.break` as a working-tree lock entry.
  - **#7, schema types:** a non-string schema `type` is an unsupported schema, not a `TypeError`.
  - **#9, collision keys:** `collision_key = NFC(NFD(casefold(NFD(name))))`, the canonical caseless match (G.3.6).
  - **#10, Markdown at line start:** `escape_markdown(line_start=True)` escapes a `~~~` fence and a leading space.
  - **#11, request size:** the request limit is 64 MiB, checked by the parent in both modes
    (`worker.request.too_large`), and a worker `FAIL` for an unreadable request keeps its reason.
  - **#12, admission tickets:** a D-554 ticket is released when the worker cannot be spawned.
  - **#13, `fork_exec`:** the worker replaces `_posixsubprocess.fork_exec` after preload (G.4.4).
  - **#14, `--offline-check`:** `backends build --offline-check` holds the environment's use lock and live staging.
  - **Rejected:**
    - for #3, pre-walking the central directory to reject one member;
    - for #6, `fcntl` or `msvcrt` (the module is host-independent by design) and rename-and-restore (it still races
      with three processes);
    - for #4, dropping the sexagesimal resolver (it changes values such as `1:30`, which would need a version bump);
    - for #11, staging member lists as inputs (a protocol change).
  - **Not touched:** D-1 (`ingest/paths.py` NFC) is cli-robustness's.
