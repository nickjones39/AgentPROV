    withheld alone"). Only a `withhold` address (a model-written address at a public mail provider, in executions) is
    meant to take executions with it.

    that holds only `withhold-object` digests is withheld alone. A raw object that holds a `withhold` digest still
    withholds the executions that cite it. A derived file that holds either still withholds its execution, so no released
    file holds a listed address (the `chain` and deposit backstops match both classes, unchanged).
    `withhold_address_classes` gives the two sets; `load_policy` takes `object_addresses`.
