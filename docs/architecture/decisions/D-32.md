- **D-32 (2026-10-11, raw objects of `recompute --out` and `derive --out` are copied by default; `--link-raw` hard-links
  them; user-approved).** Each object is copied through `RawObjectStore.put_stream(..., expected_sha256=...)`, so it is
  re-hashed while it is copied. With `--link-raw` each object is hard-linked (`os.link`) from the source store, falling
  back to a copy with a notice when the file systems differ. `CorpusLayout.iter_tree` admits hard links and
  `testing.fs_guard` ignores `ctime` and the link count. This supersedes MN N.2.4(6) (link by default) for the default.
  - **Why:** a new version is released, moved and deposited independently of its source; a hard link ties the two trees
    to one inode. Linking is still available for large stores (the 2024-06 AgentDojo corpus).
  - **Rejected:** link by default; referencing the source store (the output would not be self-contained); copying
    without re-hashing (the inputs-first rule applies to the copy).
