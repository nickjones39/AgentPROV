- **D-845 (2026-10-28, GUI Viewer tabs: keys, menus and accessibility; user decision 2026-10-28: approved as proposed in
  `docs/reports/gui/viewer-tabs/design.md`).**
  - Return in the executions table opens a tab; ⌘W closes the current execution tab (the window on the Corpora tab);
    ⌥⌘W closes the other execution tabs; ⇧⌘W closes the window; ⌘⇧] and ⌘⇧[ switch tabs (Qt's NextChild and
    PreviousChild elsewhere); ⌃Tab and ⌃⇧Tab switch sub-tabs; a middle-click closes a tab.
  - Menus: File › Open in New Tab, Close Tab, Close Other Tabs, Close Window; Go › Corpora, Next Tab, Previous Tab; a tab
    context menu with Close, Close Other Tabs, Show in Corpora, Reload Execution, Copy Execution Id.
  - Accessible names: "Viewer tabs", "Corpora browser", "Close ‹id›", and a description per execution tab with its
    corpus and load state.
  - **Byte class 0:** `gui/` only.
