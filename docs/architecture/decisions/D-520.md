- **D-520 (signals).** SIGHUP joins SIGINT and SIGTERM: the first one raises `Interrupted` (a `KeyboardInterrupt`), so
  the command flushes, seals what it can, releases its lock and exits 130. A SIGHUP inherited as ignored (`nohup`) stays
  ignored. The summary notice names the signal. The second signal kills the live T2 worker trees before `os._exit(130)`
  (CC-27).
  - **Rejected:**
    - exit 129 for SIGHUP (one interrupted code is what N.1.3 and resume tooling expect);
    - ignoring SIGHUP outright (a closed terminal should still stop the job, cleanly).
