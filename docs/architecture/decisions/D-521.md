- **D-521 (shared state outside a corpus: guard G6a).** Two primitives in `agentprov.io.locks` reuse G6's `O_EXCL`
  record `{pid, host, command, started}`:
  - `ResourceLock`, exclusive. It covers the fetch cache's write path (`<cache>/.agentprov.lock`; cached reads never
    lock) and a backend environment's build (`$AGENTPROV_HOME/locks/envs/<env>.lock`).
  - `ResourceUse`, shared registrations. `run` registers as a user of its environment and of staging; a build refuses
    while a live user exists, and a run refuses during a build.

  **Bounded:** no lock waits, and a dead holder on this host is removed, because every protected operation is
  idempotent. A live, foreign or unreadable holder refuses at once with `io.resource_busy` (exit 4), naming the holder.
  - **Rejected:**
    - `fcntl`/`msvcrt` locks (a platform branch, D-7);
    - waiting for the lock (a hung holder would hang every job; the GUI serialises with slots, D-392);
    - `--break-stale-lock` for these (unlike a corpus, nothing here needs a human to judge a resume);
    - one lock per cache entry (`acquisitions.jsonl` and `purge --cache` span the cache; writes are rare);
    - lock files inside `envs/` or staging (`info` lists `envs/`, and staging directories are scanned as evidence).
