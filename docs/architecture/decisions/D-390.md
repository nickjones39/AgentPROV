- **D-390 (2026-10-14, GUI toolkit; approved as direction 2026-10-14 by the user, relayed by the orchestrator session; build after the regeneration round).** The GUI uses **PySide6 6.12 / Qt 6.12, Qt Widgets only**, from the `PySide6-Essentials` wheel.
  - **Licence:** LGPLv3, met by dynamic linking (PyInstaller one-folder), licence texts, a source offer and relinking
    instructions.
  - **Not used, and excluded from bundles:** QtWebEngine, Qt Quick/QML, QtNetwork, Qt Charts, Qt Graphs and Qt Data
    Visualization (the last three are GPL only).
  - **Evidence** (`docs/reports/gui/research.md` Q1):
    - PySide6 has supported 3.14 since 6.10.1, with `cp310-abi3` wheels;
    - native accessibility on all three OSes;
    - model/view virtualisation (paint cost flat from 10k to 1M rows; 100k-row model-side sort in 86 ms);
    - Graphics View with a BSP index and LOD (10k nodes interactive when zoomed in);
    - follow-system theme APIs.
  - **Amendment (2026-10-14): user decision 2026-10-14: G1–G2 build starts before the round; G3+ unchanged.** The
    build runs on branch `gui-build` (session "GUI build"); progress and deviations are in
    `docs/reports/gui/build-log.md`.
  - **Rejected:**
    - PyQt6 (GPLv3 or commercial);
    - Tkinter (no screen-reader support on the bundled Tk 8.6; Treeview has no virtual mode);
    - Textual as the main GUI (terminal; `textual serve` / textual-web are servers). It is kept as a possible later SSH
      companion;
    - Dear PyGui (no accessibility);
    - Toga (slow tables, no graph canvas);
    - Slint (Python bindings in beta; GPLv3 or attribution licence);
    - Tauri, Electron, pywebview, NiceGUI and Flet (web view, server or client/server);
    - Qt Quick/QML (AutoText default, CVE-2025-12385 guidance, deploy weight, no gain).
