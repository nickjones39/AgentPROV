- **D-524 (`render` layout limit).** An image is laid out only for a graph of at most `--max-edges` edges (default 800;
  0 = no limit). Above it the `.dot` text is written, `dot` is not started, and the execution fails with
  `render.graph_too_large`, with one message naming the remedies.
  - **Rejected:**
    - a per-bundle mode (the assessment bundle alone reaches 2,342 nodes, so it does not help the large case);
    - `dot` fast flags by default (they change the drawing of every render);
    - a higher timeout (minutes per execution under `--jobs 4`).
