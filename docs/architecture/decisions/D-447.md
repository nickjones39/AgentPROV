- **D-447 (2026-10-14, GUI macOS packaging; user decision 2026-10-14: approved as direction; refines D-399).**
  - **Signing:** a Developer ID Application signature, the hardened runtime and a secure timestamp; notarised and
    stapled.
  - **Distribution:** outside the App Sandbox and the Mac App Store.
  - **Entitlements:** none to start with. Library-validation or executable-memory exceptions are added only if the
    bundle test shows a need.
  - **Keys:** entered in the signed bundle. The CLI never reads the keychain (D-395 unchanged).
  - **Evidence:**
    - a sandboxed probe could not run the venv CLI or Homebrew `dot`, or reach `~/.agentprov` (M11);
    - with temporary exceptions added, the nested `sandbox-exec` used for live containment still failed with
      `sandbox_apply: Operation not permitted` (M12).
  - **Rejected:**
    - App Sandbox with temporary exceptions (breaks containment; subject to App Review discretion);
    - an embedded, inheriting helper (the CLI must be the checkout's own, D-399);
    - the Mac App Store (sandbox required; guideline 2.4.5(iii) forbids processes that outlive the app).
