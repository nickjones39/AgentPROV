- **D-5 (Zenodo for AgentPROV).** AgentPROV corpora get a **brand-new Zenodo record and concept DOI**.
  They are never a new version of the AgentDojo-PROV concept. The release builder (`release/`) MUST
  provide an upload script that:
  - reads the user's own `ZENODO_TOKEN` from the environment (the token is never handled, logged or
    stored by AgentPROV tooling or by coding agents);
  - creates a **new deposition** as an **unpublished draft** with deterministic archives, checksums and
    metadata;
  - leaves publication to the user, who presses Publish in the Zenodo web UI after review.
