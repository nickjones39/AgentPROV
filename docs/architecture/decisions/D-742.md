- **D-742 (2026-10-23, the Inspect worker's own preflight probe; found by the first D-667 probe attempt; class 0).**
  - **Found.** The first real D-667 probe run stopped at preflight with exit 3 (`cli.environment.preflight`). The
    Inspect worker inherited the shared op `probe`, whose `runner.run_probe` imports `agentdojo.functions_runtime`
    before it builds a client. An Inspect environment has no `agentdojo`, so the worker raised `ModuleNotFoundError`
    before any HTTP request. No model call was made, nothing was charged and no corpus was written. Tests had missed
    it because a scripted run skips preflight, and no test ran `--preflight-only` through an Inspect worker.
  - **Fix.** `InspectWorker.op_probe` (`agentprov_backend_inspect.probe`) sends the D.10.9 request (the shared
    `PROBE_PROMPT` as the system message, `"Probe."`, the two probe tools) through the path a cell uses:
    - `models.build_model` (Inspect's OpenAI-compatible provider, `max_retries=1`, the SDK's own retries off);
    - the shared async recording transport and a `WireObserver` (`role: agent`), in its own capture session
      (`cell.task_id = "preflight_probe"`, artefacts `supporting`), with `inspect.preflight_probe@1` in its
      instrumentation and the note `inspect/preflight_result`.
    The results have the shared probe's shape and use its verdict functions (`roles_verdict`, the A4 text-call marks),
    so T0's A9, A3 and A4 rules apply unchanged.
  - **A3.** An Inspect cell transmits none of the agent's sampling parameters (its `GenerateConfig` sets
    `max_retries` only), so the probe configures none either: a configured `temperature` or the like shows as not
    transmitted, which is what a cell would do.
  - **Guards.** A backend test checks that `InspectWorker` overrides every shared `op_*`, so no shared op can run
    AgentDojo-family code in an Inspect environment. Scripted `--preflight-only` runs through the real worker are now
    tested for every live backend kind (agentdojo already; inspect-agentharm, autodojo and agentdyn added).
  - **Effects.** Class 0 (`backends/`, tests and docs): no stage digest moves. The installed
    `agentprov_backend_inspect` files change, so `inspect-agentharm-e3a9a78c` is rebuilt (same lock id) before the
    probe is re-run.
  - **Rejected.** Skipping preflight for Inspect backends: the probe is the only check of the endpoint's roles and
    tool calls before paid cells (D.10.9, D-291).
