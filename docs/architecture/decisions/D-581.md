- **D-581 (2026-10-21, artefact catalogues: fitting the pre-check drafts to the schema; user-approved 2026-10-21).** The
  wave-1 dossiers of the corpus pre-check (`docs/reports/precheck/`) drafted catalogue entries that the D.15.8 item 3
  schema rejects. They are fitted, not loosened (spec D.15.8 item 13):
  - a cause outside the closed list becomes the known cause or `unknown`;
  - a `DS` (datasheet) class becomes an `FO` entry whose description states the disclosure;
  - `pending`, `proposed` and `plausible` statuses become `unverified` (or `verified` for a confirmed count over the
    whole population);
  - a pre-registered estimate gets no row;
  - a placeholder detector becomes the existing rule whose output the recount reads, with no `recorded_as` and no
    `claims`, so such an entry claims no safety-net finding.
  - **Why:** the schema is what makes counts comparable across sources (D.15.3); a free-text detector cannot be checked
    by `check_references`.
  - **Rejected:** new reserved detector rules (a rules-catalogue change for entries that detect nothing per trace); a
    schema extension for analysis-only entries (a shared-layer change for a documentation need); a generic
    `arm_coverage` detector (a corpus-level property, not one execution's).
