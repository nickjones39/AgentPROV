- **D-820 (2026-10-28, `run --tune-jobs`: the concurrency sweep of N.2.1a(4); approved 2026-10-28 by the user (relayed by the orchestrator, "approve all for me as recommended", and confirmed in the calibration session's window); design note `docs/reports/mac-studio-calibration/design.md` §1, §2, §4).**
  - **Finding.** The option did not exist; `cli/run.py` refused every live run with a preset (exit 5).
  - **Built.**
    - `run SOURCE --m5ultra --tune-jobs N[,N…] [--tune-out DIR]` (default `$AGENTPROV_HOME/calibration/tune-jobs-<UTC>`).
    - **Sample and arms.** The default sample is 24 cells. One working corpus per arm, because `jobs` is not part of
      the configuration digest, so a shared corpus would resume the second arm as already done.
    - **Before the arms.** One consent and one probe, then one unmeasured warm-up cell.
    - **Order.** The order given; it is recorded.
    - **Skip and stop rules:** `memory` above `J_memory`; after an arm with timeouts or a failed cell, and after a
      canary, setup or cap stop, the higher arms are skipped.
    - **Resume** by arm file (`<out>/arms/jobs-<N>.json`, outside the corpus folders, so no undeclared file lands in
      a corpus); an unfinished arm is renamed `*.interrupted-<stamp>`, never deleted.
    - **Code:** `agentprov.cli.live.tune` (pure) and `cli/run.py` `_tune_sweep`; `_execute` gains an `on_done`
      hook and a `preset` record.
  - **As built, beyond the note.**
    - `max_attempts` defaults to 2 in a sweep.
    - The report lists `reused_arms`.
    - Notices are not printed in every output mode, so the report is the place to read them.
  - **Class 0:** `cli/`, `presets.py` and `presets.toml` are in no stage digest; no capture or backend change.
  - **Rejected:**
    - one corpus for all arms (the resume collision above);
    - interleaving arms cell by cell (the prefix-cache state would then mix concurrencies);
    - a random order per run, which a single sweep cannot average out. The order is recorded instead.
  - **Tests:** `tests/unit/test_tune_jobs.py`, `tests/integration/test_run_tune_jobs.py` (scripted sweeps against
    the fake backend: arms, report, resume, memory skip, dry run, refusals).
