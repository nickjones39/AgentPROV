- **D-8 (2026-10-08, live feedback; user requirement, architect ruling).** Long-running commands, live trace runs
  above all, give levelled live feedback on stderr: `--progress off|summary|status|steps|trace`, formats
  `tty|plain|jsonl` and an optional `--progress-file`, specified in MN N.1.14. Feedback is metadata only by default;
  `--show-content` adds escaped excerpts. It is a separate channel from logging. The binding guarantees:
  - feedback never changes evidence bytes (F1);
  - the capture never waits on the display: bounded, droppable queues, a dedicated pipe reader and a throttled
    renderer (F2);
  - overhead is measured and reported (F3);
  - no decision reads the level (F4).

  **Rejected:**
  - routing progress through `logging`: handler I/O runs synchronously in the emitting thread, which would let a
    slow terminal back-pressure the capture;
  - a third-party progress library such as `rich` or `tqdm`: a new core dependency, and terminal-escape handling
    over untrusted strings.
