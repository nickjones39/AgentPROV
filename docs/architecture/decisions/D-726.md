- **D-726 (2026-10-22, consent by endpoint class; user decision).**
  - `local` runs take the interactive prompt, `--i-consent-to-local-run` or `--i-consent-to-api-costs`.
  - `api` runs take the prompt or `--i-consent-to-api-costs` only.
