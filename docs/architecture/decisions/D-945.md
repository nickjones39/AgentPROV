- **D-945 (2026-10-29, synthetic fixtures replace the five copyleft fixture sets; carries out D-943 P-1, the release
  blocker of 2026-10-12; byte class 0).** The real excerpts of gate, SENTRY, aiAuthZ, bookkeeper and llm-lock (AGPL-3.0
  and GPL-3.0 logs) were committed as `licence_class: restricted` fixtures, with their five licence texts, for the
  private repository only. P-1 asks for them to be replaced by synthetic fixtures before the release commit, so that the
  public repository keeps the tests of these five dialects.
  - **Decision.** The 14 real logs of `tests/fixtures/{gate,sentry,aiauthz,bookkeeper,llm-lock}/` and
    `tests/fixtures/LICENSES/{gate-AGPL-3.0-only,SENTRY-AGPL-3.0,aiAuthZ-AGPL-3.0,bookkeeper-GPL-3.0-or-later,llm-lock-GPL-3.0}.txt`
    are removed from the tree (`LICENSES/SOURCE.json` never listed them). They are replaced by 14 self-authored
    AgentDojo TraceLogger logs, written by `tests/adapters/agentdojo/phase10d_synthetic.py` at the paths of the logs they
    replace. Each synthetic log therefore has the same layout facets, identity row, variant (`v1.k14`,
    `v1.k14.incomplete`) and benchmark label as the log it replaces. It also keeps that log's dialect feature, chosen by
    the criteria of `tools/agentdojo/phase10d_fixtures.py`:
    - gate: the denial logged as both content and error, with a null call id (an orphan result), and the empty hold-out
      run with no outcome;
    - SENTRY: the unresolved free-router directory, and a null `benchmark_version`;
    - aiAuthZ: null final replies (three passes inferred), and the policy denial with an empty output;
    - bookkeeper: the Munim money-gate denial, an attacked `read_file` run, an incomplete run, a null
      `benchmark_version` and CRLF line ends;
    - llm-lock: the `llm` arm's detector abort after a tool output (D-116), its extra top-level classifier keys, the
      hybrid and undefended arms, and every directory unresolved (D-92).

    Mapped, each synthetic log gives the same record kinds, issue codes, actors and decisions as the real log it
    replaces. The one exception is llm-lock's `agentdojo.system_prompt_unrecognised` (see below). The `SOURCE.json`
    entries follow the FooBench pattern: `synthetic: true`, `licence_class: permissive`, the repository's MIT licence,
    `original_path` naming the generator, `layout_of` naming the profile's primary pin, and the placeholders filled at
    run time. The new AER digests replace the old ones under the same 14 keys of `phase10d_aer_digests.json`.
  - **Assembled at run time (K.4.1(3), R-42).** A template stores a placeholder for two values, and the test support
    fills it when the test runs:
    - the injection sentence of an attacked log, joined from fragments in the generator;
    - AgentDojo's default system prompt (MIT), read by its pinned digest from the permissive
      `tests/fixtures/agentdojo/head/` fixtures. This keeps the `agentdojo_default` prompt pin of four profiles in use,
      and the test now asserts that label.

    llm-lock's own prompts are GPL text and are not reproduced. Its synthetic logs carry a self-authored prompt, so they
    raise the info issue `agentdojo.system_prompt_unrecognised`, and no fixture exercises the `llmlock_default` digest
    any more.
  - **Tests.** The 7 modules that use `phase10d_support.py` are unchanged except `test_phase10d_sources.py`. Its
    real-fixture tests run on the synthetic logs too: they map, validate in release mode, cite only twins, keep their
    AER digests and annotate under `agentdojo.suites@2`. For these five sources, the licence-text check is replaced by a
    provenance check: the `SOURCE.json` fields, byte equality with the generator output, and no licence file of the
    source. A new test checks that no template holds the injection sentence, and another that the committed files are
    what the generator writes. Weakened:
    - `test_fixtures_are_provenanced_and_licensed` no longer checks the upstream commit, the repository and the copyleft
      licence marker for these five sources, because no upstream bytes remain;
    - the AER digests now pin synthetic bytes, so the tests no longer show that the mapper reproduces real copyleft
      logs. The phase-10d trial imports and the sealed corpora remain that evidence;
    - llm-lock's prompt-digest label, as stated above.
  - **Bytes (class 0).** Only `tests/`, `THIRD_PARTY_NOTICES.md` and documentation change. No profile, catalogue, table
    or file under `src/` changes, so no stage digest or corpus moves. The real excerpts stay in the private development

  - **Rejected.**
    - Deleting the five fixture sets without a replacement: it would drop the real-file tests of five dialects, including
      the only real detector-abort and CRLF logs.
    - Moving them under `fixtures/synthetic/`: the tests and the digest pins key on `tests/fixtures/<source>/` and the
      upstream path (FooBench keeps its own directory too).
    - Generating the logs in memory with no committed files: K.4.1 wants a `SOURCE.json` entry for every fixture, and a
      committed file can be checked byte for byte against its generator.
    - Rewriting the real logs (replacing their text): what remained would still derive from AGPL and GPL works.
    - Writing AgentDojo's default prompt into the templates: the fixture files would then hold MIT text under the
      repository licence. It is read from the MIT head fixtures instead.
