- **D-650 (2026-10-22, GUI G3: a shipped, dated price table, overrides and a confirmed refresh; amends design §8.3's "no
  prices are shipped"; user decision 2026-10-22, relayed by the orchestrator).**
  - **Why.** The Run live form must show the estimated USD cost of the whole run once the user picks an endpoint and
    a model: p50 and p90, per suite and per attack, plus the time. It is recomputed whenever the cells, attacks,
    benign mode, repeats or model change. Asking the user to type every price first made the estimate useless.
  - **What.**
    - `gui/src/agentprov_gui/data/prices.json` (`agentprov-gui-prices/0.1`) holds, per row, the provider, model id,
      USD per million input, output, cached-input and (Anthropic) 5-minute cache-write tokens, the source and the
      `as_of` date.
    - It is built by `gui/tools/build_price_table.py` from two inputs:
      - a dated OpenRouter `/api/v1/models` snapshot (its sha256 recorded, the snapshot itself not committed);
      - `gui/tools/price_direct.toml`: the OpenAI, DeepSeek and Anthropic pages, transcribed with source and date.
    - First build: 394 rows as of 2026-10-21 (the user's one-time fetch yes, 2026-10-22; Anthropic added at the user's
      request the same day).
    - Precedence for one endpoint and model:
      - a Settings › Prices override, with the date entered;
      - the newest refreshed snapshot (`$AGENTPROV_HOME/gui/prices/openrouter-<date>.json`);
      - the shipped table.
    - Routing: an `openai` or `deepseek` id without a direct row falls back to OpenRouter's `openai/*` or
      `deepseek/*` row, labelled "may differ". The `anthropic` endpoint has no fallback (OpenRouter's ids differ).
      Local endpoints (`local = true`) cost nothing per token.
    - Every estimate shows the price's date and source, with a warning past 60 days.
    - **Refresh prices** is a GUI tool job (`gui/tools/fetch_prices.py`, tier R2), confirmed with the tick box every
      time and never automatic. The tool is stdlib only: a fixed URL (or loopback, for tests), no redirects, no
      environment proxies, 16 MiB, saved unparsed. The GUI then parses it only through `agentprov.ingest` (strict,
      bounded JSON), keeps ids and prices only (no names or descriptions), writes the dated snapshot and removes the
      raw file.
  - **Rejected.** No shipped prices (the original §8.3: a cost estimate nobody can see); fetching in the GUI process
    (S11: no network module); refreshing on start or on a timer (a network call without consent); scraping provider
    pages at refresh time (HTML is fragile and untrusted; OpenRouter's JSON covers every routed endpoint).
  - **Class 0.** GUI only. **Tests:** `gui/tests/test_estimate.py` (strict parse, lookup order, staleness, the shipped
    table's coverage), `gui/tests/test_g3_live.py::test_refresh_prices_against_a_local_stub`.
