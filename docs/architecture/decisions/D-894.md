- **D-894 (2026-10-28, a configurable size cap for the tier-4 round-trip cache: `compute.validation_cache_gib`; M5 Ultra
  performance round 2, item 1c; the user chose 32 GiB for the Mac Studio).**
  - **Finding.** The D-550 cache (`$AGENTPROV_HOME/cache/tier4`) is one LRU store capped at 2 GiB (`DEFAULT_MAX_BYTES`),
    shared by every command and session on a machine. A miss costs about four times a hit:
    - `recompute --dry-run --jobs 3` on `ast-survey-agentdojo-rg2`: 105.7 s warm, 400.9 s with `--no-validation-cache`;
    - a cold run at `--jobs 8`: 199.3 s against 72.4 s warm.
    One large corpus (`agentdojo-upstream-2024-06-rg1`, 18,241 executions) can evict a smaller corpus's entries. During
    round 2, a run right after the large corpus's warm-up spent 1,705 CPU-seconds where a warm run spends about 330.
  - **Change.** The setting `compute.validation_cache_gib` (GiB, 1–4096) caps the cache for every command that uses it.
    - The commands are `validate`, `derive`, `recompute`, `verify --level rederive` and `import`. All of them build it
      through `cli/checks.validation_cache`.
    - Unset, the cache keeps its own 2 GiB default.
    - The cap only bounds the eviction after a run. It never changes an outcome, because a hint is re-checked by the
      job (D-550).
  - **Recommended:** 32 GiB on the Mac Studio (the user's value; its `AGENTPROV_HOME` volume has 1.7 TiB free):
    `agentprov settings set compute.validation_cache_gib 32`. The M2 Max keeps the default.
  - **Not changed:** the built-in default in `validate/cache.py`. That file is in the validation stage scope, so raising
    the default is class 1 and waits for the round-1 seal.
  - **Rejected:**
    - a `--validation-cache-gib` flag on each command: five commands to keep in step for a per-machine fact;
    - an environment variable alone: invisible in `settings list`.
  - **No GUI control.** The reverse-parity rule (D-700) needs every GUI input to be a CLI setting, not the other way.
  - **Class 0:** `cli/checks.py` and `settings.py` are outside every stage scope.
