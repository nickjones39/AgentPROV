- **D-705 (2026-10-22, `agentprov devrun`; part of D-700).**
  - **What.**
    - `agentprov.devrun.plan` holds the pure part, moved from the GUI: the settings (`agentprov settings` `devrun.*`,
      D-703), the part plan, the per-part summary and the run listing. It is read-only, and the GUI imports it for
      the Settings › Dev Runs preview and the Runs › Dev Runs table (D-391 allowlist).
    - `agentprov devrun plan|start|list|prune` (`cli/devrun.py`) does everything that writes:
      - `plan` gives the parts, sample counts and three steps per part, and writes nothing;
      - `start --confirm-r2` (exit 4 without it: the imports read the fetch cache) creates
        `dev-runs/<UTC stamp>/` and its `devrun.json` (`agentprov-devrun/0.1`), creates the batch (D-704,
        continue on failure, the checkout pin) and starts its driver job;
      - `start` then deletes all but the newest `devrun.keep` run folders, sparing every folder a running job or an
        unfinished batch uses (GR-25), and only real run folders, never a link (GR-26);
      - `list` gives the runs, newest first, with a summary per part;
      - `prune` lists old runs, and deletes them with `--yes`.
    - The steps are the GUI's (D-544, D-529):
      - `import --snapshot PART --fetch --sample N --sample-mode M [--seed S]` into `<run>/<part>`;
      - `validate`;
      - `recompute --dry-run`;
      - each step goes through the machine-wide job queue when the checkout has `tools/suite_queue.py`;
      - never `--release` and never a stored corpus;
      - with `devrun.prov_conformance` off, the import skips tier 4 and validate runs `aer,sem,linkage` (§8.3a).
    - The settings schema's override key widens to `devrun.override.SOURCE[.PART]`.
  - **GUI.**
    - Start Dev Run shows the CLI's plan, asks, and runs `devrun start --confirm-r2`.
    - Settings › Dev Runs reads `devrun.*` with `settings list` and writes only the keys that changed, through
      `settings set` and `unset`. The pane stays disabled until it has read them.
    - `gui/jobs/devrun.py` and the `devrun/settings` QSettings key are gone.
  - **Not yet:** the live dev run's model-call cap is still enforced by the GUI draining the job. With D-725 it can
    become `run --max-calls`, and that change is recorded for the hookup work.
  - **Rejected:** keeping the planner in the GUI (the CLI could not start a dev run); the old
    `agentprov-gui-devrun/0.1` folders are not migrated, and are neither listed nor pruned.
  - **Class 0.**
  - **Tests:** `tests/devrun/test_devrun.py` (the settings keys, the plan, the steps, `start` without and with
    `--confirm-r2`, prune sparing busy runs, links and non-runs, the listing, the summary);
    `tests/devrun/test_devrun_names.py` (GR-26, moved); GUI `test_review_devrun_prune.py` and `test_g4_followups.py`
    (the fallback end to end).
