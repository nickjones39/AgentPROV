- **D-230 (2026-10-12, withholding session: the `agentprov-withheld/0.1` format; user-approved 2026-10-13).** `WITHHELD.json` is a corpus-layer single JSON document `{format, entries, executions, policies}` with a
  new published schema `schemas/withheld-0.1.schema.json`. It is generated from `agentprov.corpus.withheld` and frozen
  with its version (D-163). A sealed corpus that holds `WITHHELD.json` also holds a copy of that schema, and `chain`
  compares the copy byte for byte with the package's. `entries` keeps G.9.5's object shape and adds `basis` (`purge`,
  `raw_policy`, `profile_rule`, `container`). `bytes`, `media_type`, `finding` and `decided_on` are nullable and never
  filled with placeholders. `origins` holds the object's `raw/origins.jsonl` origins (at least one). `executions` gives
  each withheld execution's id, snapshots and stage digests (the index row's `digests`), so it can be recomputed
  locally from the pin and checked. `policies` names the profile `[withhold]` policy applied: rule ids, kinds and
  scopes, never a marker or pattern. Neither the value nor any fragment of it is recorded. The source key is not kept
  either, because its locator can hold source-derived names (D-146's account paths).
  - **Why:** G.9.5 fixes the object shape. Recomputing an execution needs its identity and digests, and the document
    must stay safe to publish.
  - **Rejected:** keeping only G.9.5's `entries` (a withheld execution could not be checked after a local recompute);
    recording the source key (it can carry personal paths); copying the profile's markers or patterns (they live in
    `rules/<profile>.profile.toml`).
