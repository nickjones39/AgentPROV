- **D-9 (2026-10-08, trace concurrency; user requirement, architect ruling).** `agentprov run --jobs N` sets the
  number of concurrent traces (backend workers). The baseline hard-coded 18. The rules (MN N.1.10(1)):
  - the default is 1, and N ≥ 1;
  - N above the host maximum (D-7 memory budget) is refused with that maximum named; it is never clamped silently;
  - `--start-stagger SECONDS` is a deterministic start spread that replaces the baseline's random sleep;
  - both values are recorded with the run.

  **Rejected:** a fixed default above 1 (paid endpoints), and an env-var default (hidden configuration of paid,
  recorded runs).
