- **D-725 (2026-10-22, API caps; user decision).**
  - **Required.** An `api` campaign needs `--max-calls` and `--max-cost-usd` (with `--price-in` and `--price-out`).
    Otherwise `cli.refused.api_caps`, exit 4.
  - **Budget.** T0 starts a cell only if the corpus's spend plus every in-flight cell's worst case and its own fit
    both caps. The worst case is 48 billed calls at the per-call token bound.
  - **Spend.** Taken from the recorded `usage`, priced as an upper bound.
  - **Stops.** A cell over the call bound stops the campaign. `--preflight-only` is one call and takes no caps.
  - **Backstop.** The provider-side key or workspace limit, which the user sets.
  - **Rejected.** A per-call stop inside the worker: it needs `backends/shared` and misses the env-rebuild window.
