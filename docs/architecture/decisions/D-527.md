- **D-527 (2026-10-14, the control file as built; refines D-394).**
  - **Polling:** a daemon thread `stat`s the file at most once a second. It is not polled per unit, because the
    commands' unit loops are in other sessions' files; one `stat` per second meets the "≤ once per second inside long
    units" bound.
  - **Ignored:** a request already present at start, and a seen nonce.
  - **`stop`** is `_thread.interrupt_main(SIGTERM)`, the first-SIGTERM path, which is graceful on Windows too.
  - **The summary notice** names the request and nonce.
  - **Rejected:**
    - acting on a request present at start (re-running the same argv after a drain would stop at once);
    - `os.kill` of the own pid (not graceful on Windows).
