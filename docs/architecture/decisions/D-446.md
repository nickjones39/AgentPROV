  - The graph is exposed through an Elements list plus a custom `QAccessibleInterface` for its nodes; the list alone

  - Increase Contrast tokens apply; under Windows contrast themes only system colours are used.
  - Bundle letters are shown when Differentiate Without Colour is on.
