  strictly to its message; an array pointer would dangle (found by the scratch trial's evidence-linkage tier, 2026-10-15). The empty output is registered
  `select.not_execution_artefact` (`qwencode.empty_output`); the 5 API samples are supporting artefacts, not executions.
