- **D-528 (2026-10-14, `run --env-stdin` details; refines D-395).**
  - **Accepted names:** the union of `api_key_env`, `base_url_env` and `model_env` over `endpoints.toml`, plus
    `REASONING_EFFORT`. The selected endpoint's names are then taken, as from `.env`.
  - **Values are strings.** A `*_API_KEY` value, or the value of an unknown name, is registered for redaction before
    any message is formed.
  - **Refused with `--llm-script`** (a scripted run needs no key) and exclusive with `--env-file`.
  - **Rejected:**
    - accepting only the selected endpoint's names (the GUI sends one object per endpoint choice, so this is the same
      thing; the union keeps the parser independent of model selection);
    - reading stdin after model selection (D-395 says before any other step).
