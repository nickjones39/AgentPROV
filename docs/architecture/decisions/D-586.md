- **D-586 (2026-10-21, melon: the MELON defences' own messages; user-approved 2026-10-21).** `melon-agentdojo` version 2
  declares the quirk `agentdojo.melon_defence_messages` (hook `hooks/melon.py`). It uses a new optional hook point,
  `message_author` (`quirks.py`), which is called for every system message before the positional rule and for every
  agent assistant message without calls. The quirk lists, per defence, the digests of the logged texts (pre-check
  PC-melon-agentdojo-03/04):
  - base MELON's stop message (`melon`, `melon_at`, `melon_sm`; 910 logs, one per sentinel) and MELON-R's block message
    (3 logs) become a `terminate` decision by the defence actor about the model call: the reply is `/original`
    overwritten. The decision generates the message, which the defence wrote. The model call stays and generates
    nothing;
  - MELON-R's three security warnings (113 system messages in 98 logs, 92 at index 0) are the defence's inserts;
  - the default prompt standing after a warning is the harness's, by its digest.

  Rules `agentdojo.defence_authored_message@1` and `agentdojo.system_prompt_by_digest@1` (class I) are appended to the
  `agentdojo` catalogue v2 in place (D-31 owner ruling 2026-10-21). The `melon_r_prompt` variant of version 1 is
  dropped.
  - **Why:** defence-authored content was mapped as model output (`generated_by` the model call, which the pinned
    `MELON.query` contradicts) and as the benchmark's system prompt. Outcomes are unaffected.
  - **Rejected:**
    - dropping the model call (it ran: MELON queries the model, then replaces its reply);
    - a `redact` verdict (the defence ends the run rather than editing a value it passes on);
    - matching the texts in the generic mapper (byte changes for every profile);
    - the pinned code's warning text as the match (it is longer than every logged warning; the logs predate it).
  - **Not done:** the sanitised tool outputs (PC-05, routing R3) and the proposed catalogue entry
    `agentdojo.art.defence_authored_message` (a new code, put to the user separately).
  - **Byte class 1:** regeneration-batch item 113.
