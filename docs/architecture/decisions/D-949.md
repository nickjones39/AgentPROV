- **D-949 (2026-10-29, follow-ups to D-947: copyleft datasheets, where a collection is drafted, the trial script and the
  cross-link membership check; the user approved the orchestrator's five recommendations, relayed: "approve my 5
  recommendations").**
  - **(1) No copyleft datasheet under the CC-BY-4.0 index.** A corpus whose licence class has a copyleft term (GPL,
    AGPL, LGPL; `agentprov.corpus.licences.is_copyleft`) keeps its datasheet only in its part record: its
    `COLLECTION-INDEX.json` row records the datasheet's `location: part` with its name, size, sha256 and md5, and the
    README names the part record. Every other corpus's datasheet is copied (`location: index`).
    `check_index_deposit` checks each `location` against the corpus's class and the closed world against the copied
    datasheets only. The licence-class rows (SPDX id and restriction texts) stay: they are AgentPROV's description of
    each part, not copyleft text. `agentprov-collection-index/0.1` is amended in place: nothing built with it has been
    uploaded or published.
  - **(2) A collection is drafted from the terminal;** the desktop app's *Create Zenodo drafts…* is for single records.
    It asks (plain text, Cancel by default) before it cross-links two or more lines. User guide chapter 5 and H.10.7
    say so.
  - **(3) `tools/zenodo_collection_trial.sh`** trials the index-only umbrella: the parts are checked and drafted, the
    index is built from their receipts with `package --index`, checked and drafted, a cross-link without the first part
    must be refused, then it cross-links twice (the second changes nothing). bash 3.2 compatible (macOS).
  - **(4) `--cross-link` membership check.** With an index umbrella (its receipt lists `COLLECTION-INDEX.json`), the
    members must be exactly the part records the index lists, by reserved DOI and deposition, and the index read
    beside the receipt must have the uploaded file's sha256; otherwise it refuses before any request (exit 4). A
    corpus-holding umbrella is not checked (it has no index).
  - **(5)** The user runs the sandbox trial before any production draft (D-941 L-8); the steps are in
    `docs/reports/release/collection-layout.md` section 9.
  - **Rejected:** dropping copyleft corpora from the index (the index must list every corpus with its digests); a
    second, copyleft-licensed index record (one umbrella per collection, D-941 L-5); removing the GUI's cross-link step
    (single-record use and the D-880 parity stay); a GUI "parts only" mode (a dialog change beyond a warning).
  - **Byte class 0:** `agentprov.release.index` and the uploader are in no stage scope; corpus deposits and their
    manifests are unchanged.
