- **D-45 (2026-10-11, `render` is on demand only; `--all` is removed and `--select` needs `--limit`; phase 11, user rule).**
  `agentprov render` has no `--all`; a bare `render --corpus DIR` is a usage error (exit 2). Allowed selections are
  `--ex ID...`, `--limit N`, and `--select KEY=VALUE[,VALUE...]` together with `--limit N` (a filter alone can match every
  execution). Output location and guard, `--bundle`, `--format`, `--show-content`, `--jobs`, `--dry-run` and determinism
  are unchanged.
  - **Why:** with 18,000 to 35,000 executions per corpus and one Graphviz process per graph, a render-all is a job of
    hours that nobody means to start from a shell; removing the option makes the safe behaviour the only one.
  - **Rejected:** `--all` behind a confirmation flag; requiring `--limit` for `--ex` (a typed list is already finite); a
    hard cap on `--limit`; `--select` alone with a warning.
