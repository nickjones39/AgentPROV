- **D-455 (2026-10-15, bug pass bugpass-perf-10, routed R-10j-3: URL download pins as archive inputs; user decision
  2026-10-15: approved).** Phase 10j's `dca` corpus is one Figshare file pinned by `url`, and only Zenodo and Hugging
  Face download pins were archive inputs (D-200), so it could not be imported.
  - **Decision:** `DOWNLOAD_PIN_KINDS` gains `url`. `ArchiveTree` builds the origin `url {url, retrieved}`; `_pin_record`
    and `import --fetch`/`--input` follow; the seal builds `{kind: url, url, retrieved_at}` (H.2.3, `retrieved_at`
    REQUIRED because the origin is mutable). It is the same extraction-free, SHA-256- and size-checked path, with the
    network only under `--allow-network`.
  - **The retrieval time:** only from the recorded fetch, the fetch cache's acquisition record (read back on a cache
    hit too), else the pin's own `retrieved_at` (RFC 3339 UTC). With neither the import is refused
    (`raw.origin.unpinned`, exit 3; invariant 2). It is never the time of the import or a file time. The object origin
    keeps the date (`retrieved`, aer/0.1), the snapshot the full time. A pin with a date-only `retrieved` key is
    refused the same way, even beside a valid `retrieved_at`.
  - **The shipped pin:** `dca-agentdojo` records `retrieved_at = "2026-10-11T09:46:41Z"`, the phase-10c acquisition
    record of the pinned bytes (sha256, size and md5 equal), replacing the date-only `retrieved` of the dropped
    duplicate D-580. In-place D-31 (version stays 1): no corpus records the profile.
  - **Not covered:** a URL archive in byte parts (refused; split archives are pinned on Zenodo or Hugging Face).
  - **Byte class 1:** `adapters/runner/` moves the `aer` stage's code digests (regen-batch item 101); no stored corpus
    has a `url` snapshot, so no AER, SEM or PROV byte moves. Held on `bugpass-regen-d455`.
  - **Rejected:** stamping the import time (an invented timestamp); a date-only `retrieved_at` (the sealed origin needs
    RFC 3339 UTC, and a time of day must not be filled in); keeping URL pins `agentprov fetch` only (the source could
    never be sealed with a pinned origin).
