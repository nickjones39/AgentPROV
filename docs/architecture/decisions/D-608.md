  D-604): agentops-bench, a third-party account path in tool output is redacted and its raw objects are withheld.**
  Amends D-199 and D-186 (c) for this source.
  - **Context:** `run_python` output of the AgentOps-Bench pilot (result text, `stdout`, `stderr`) names one macOS
    workstation account in `/Users/<account>/` paths. D-199 kept it verbatim as tool output and called it the operator's.
    The pre-check found it is a third party's (PC-agentops-bench-01, CC-11; ruling CC-12a S0 once imported, unless a
    D-182-style rule lands first: this is that rule). D-604 sets the principle: account paths in content are redacted in
    tool and environment output only, model text stays verbatim, raw objects holding the path are withheld at object
    scope, and an execution whose derived record still holds the path is withheld (D-235).
  - **Decision:**
    - `adapters/agentops/redact.py`, a family copy of the D-476 grammar with one scope, `tool_output`: the values of
      tool messages (each part's `text` and `value`, strings and object keys at any depth), decoded with the record's
      `ext.lex` hints and encoded again, so `$utf16` and `$lit` forms are covered and the `ext.lex` entries, `evf`/`unk`
      keys and scoped rule citations below a renamed key follow it. A recorded payload suffix stays verbatim (it must
      equal its fixture) and the decision's `suffix_offset` is the offset in the redacted text. A mapper post-pass;
      each redacted pointer is `D`, cites `agentops.value_redacted@1` and is listed in `ext.agentops.redacted`; one info
      issue `agentops.value_redacted` per execution.
    - Profile rule `macos_account`: `/Users/<name>` before `/`, `<name>` in `[A-Za-z0-9._-]{1,64}` and not a D-457
      generic name; the whole `/Users/<name>` becomes `acct-{span12}` (salted with the profile id), so no AER byte
      matches the withhold pattern.
    - `[withhold]`: reason `personal_data`, rule `account-path`, pattern `/Users/[A-Za-z0-9._\-]{1,64}/`, scope
      `object`. `/home/` is not covered (its hits are `web_search` fixture text, PC-02, not an account of the run).
    - Catalogue `agentops` v2 gains the rule and the issue code; `artefacts.toml` replaces the "operator account path"
