- **D-445 (2026-10-14, GUI platform integration; user decision 2026-10-14: approved as direction).**
  - **Dock:** the badge counts running jobs; tile progress through `NSDockTile`.
  - **Notifications:** `UNUserNotificationCenter` in a signed bundle, only for jobs over 2 min when the app is not
    frontmost, never carrying data text. The fallback is a Dock bounce plus an in-app banner.
  - **Windows:** multiple windows; no window tabs (Qt disallows them).
  - **State:** restored with `QSettings`, never the Show-content toggles.
  - **Full screen:** native Full Screen and tiling.
  - **Not provided:** a Quick Look or Spotlight extension.
  - **Equivalents:** taskbar progress (`ITaskbarList3`) and toasts with an AUMID on Windows; Unity `LauncherEntry` and
    freedesktop notifications over QtDBus on Linux.
  - **Rejected:**
    - `QSystemTrayIcon.showMessage` (uses the deprecated `NSUserNotification`, QTBUG-110998);
    - a Quick Look or Spotlight extension (a sandboxed Swift `.appex`, no working `CSImportExtension` on macOS, a new
      display surface for untrusted text);
    - re-enabling window tabbing behind Qt's back.
