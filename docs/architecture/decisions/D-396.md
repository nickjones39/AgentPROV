- **D-396 (2026-10-14, GUI display security; approved as direction 2026-10-14 by the user, relayed by the orchestrator session; build after the regeneration round).** Security rules S1–S14 of `docs/reports/gui/design.md` §11 apply, each enforced by tests.
  - **Plain text only:** every text widget comes from one factory (`SafeLabel` with PlainText, `safe_message_box`,
    `ReadOnlyText`). Tooltips are `Qt.convertFromPlainText(escape_untrusted_line(s))`.
    - Measured: QLabel and QMessageBox default to AutoText, and QLabel to `LinksAccessibleByMouse`.
  - **Banned by an AST lint:** `setHtml`, `setMarkdown`, `QTextBrowser`, `QGraphicsTextItem`, `Qt.RichText`/`AutoText`,
    and `openUrl` with data.
  - **Content is hidden by default, per pane** (G.8.2). Shown content goes through `quote_untrusted`. One-line labels use
    `escape_untrusted_line`; `display_clean` avoids double escaping.
  - **Nothing from data:** no links, media or HTML; artefact media are never rendered.
  - **No GUI feature forwards content to a model.**
  - **Rejected:**
    - relying on widget defaults;
    - HTML escaping alone (it misses bidi and controls);
    - content shown by default.
