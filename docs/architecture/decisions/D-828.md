- **D-828 (2026-10-28, a local model's facts as settings, Settings › Local Models, GGUF weight sizes and a folder
  search; the user's request in the Mac Studio calibration session, design confirmed in its window).**
  - **Finding.**
    - oMLX names no model folder, and the five models served on the Mac Studio give no active-parameter count that
      `config.json` can be counted from (new MoE types).
    - Their GGUF weights were not counted: only `*.safetensors` were, so the dry run said "weight size unknown".
    - Each run needed `--model-dir` and `--active-params-b` typed again.
  - **Settings.** `agentprov settings` gains closed-schema keys
    `local_models.<endpoint>.<model id>.{model_dir, model_size_gb, active_params_b, context_tokens, kv_gb_per_trace}`.
    These are the run flags of N.2.1a(3), in the same units.
    - **The model id** is a key segment. It may hold `.`, `:` and `/`, but it is a label, never a path: the endpoint
      before it and the field after it are fixed, so the full-key match stays unambiguous.
    - **The folder** must be absolute; whether it exists is checked when it is read.
    - **Helpers:** `settings.local_model()` and `local_model_key()`.
  - **Precedence: flag > setting > the model's folder > the preset.**
    - **Where it applies:** a run with `--model-id` uses the setting in the preset dry run (and Tune) and as the
      folder of the identity record (N.2.18, `run`'s preflight).
    - **What is recorded:** the source of each value is `settings`, with the key as its note (a new `Source` value).
    - **A missing folder:** a stored folder that is no longer a directory is a usage error naming the key (exit 2),
      never a silent fallback.
  - **GGUF.** With no top-level `*.safetensors`, the weight size is the sum of the top-level `*.gguf` shards, else of
    oMLX's `split/*.gguf` links (by `stat`; never opened; links followed and recorded). Safetensors still win when
    both exist, and the two are never summed together.
  - **Folder search.** `agentprov models [--endpoint NAME] --model-id ID --find-folders` (`agentprov-model-folders/0.1`)
    looks in oMLX's `models/` and `gguf/` (under `OMLX_HOME` or `~/.omlx`), the Hugging Face cache (the `refs/main`
    snapshot) and LM Studio's models folder.
    - **Matching:** it compares folder names with the id, without its `:suffix` (an oMLX context alias or an Ollama
      tag).
    - **What it reads:** directory listings only, bounded to 4,096 entries per directory. It opens no file and
      contacts no server or keychain, and a path-like id finds nothing.
    - **Checked against the Mac Studio:** it found all five folders the oMLX server serves from.
  - **GUI.** A Settings › Local Models tab:
    - a local endpoint and an editable model id;
    - **List Models** (`agentprov models`, with `--keychain` for a keyed server, D-827);
    - the folder, with **Browse…** and **Find Folder**;
    - the four numbers, and **Clear**.

    Every model's edits are kept while switching, and OK writes only what changed through `agentprov settings`. A
    value the schema would refuse is left out. Run Live's Tune passes the endpoint and the model id, so the settings
    apply there. The reverse-parity registry maps each input and button.
  - **Class 0.** `settings.py`, `presets.py` (the weight sum and the `settings` source), `cli/run.py`, `cli/models.py`,
    `cli/live/localmodels.py` and the GUI: no stage digest, AER, SEM or PROV byte and no capture or backend change, so
    no environment rebuild.
    - **Dry-run output:** `model_dir` facts of a GGUF folder change from unknown to a size.
    - **Configuration digests:** they change only where a run now has facts it lacked. Preset live runs are still
      refused, so no corpus records these values.
  - **Rejected:**
    - Encoding the model id into a fixed-width key segment (a digest), so that the key is unreadable in
      `settings list`.
    - A separate facts file outside `settings.json`, which would be a second store with its own CLI and GUI.
    - Guessing the active parameters from the model's name or README.
    - Following the server's own folder setting (`~/.omlx/model_settings.json`), which is an undocumented format.
  - **Tests:**
    - `tests/cli/test_local_model_settings.py`: the keys, refusals, a prefix collision, GGUF top-level and `split/`
      sums, the precedence in the dry run, a stored folder that is gone, the folder search over temporary oMLX, HF
      and LM Studio trees with hostile ids, and the CLI;
    - `gui/tests/test_local_models_pane.py`;
    - the GUI reverse-parity tests.
