- **D-891 (2026-10-28, dry-run and rederive trees on the source's filesystem; M5 Ultra performance round 2, item 1a).**
  - **Finding.** `$AGENTPROV_HOME` became an APFS volume of its own on the Mac Studio (2026-10-28). A
    `derive`/`recompute --dry-run` tree, or a `verify --level rederive` tree, in the system temporary directory could
    then not hard-link the source's raw objects (D-32), so every object was copied and re-hashed ("hard links are not
    possible here"; 3,253 objects on `ast-survey-agentdojo-rg2`).
  - **Change.** `corpus/scratch.py` `scratch_tree()` makes the private tree under `$AGENTPROV_HOME/tmp` or in the system
    temporary directory, whichever has the source's `st_dev`. A corpus on a third volume, or one that cannot be
    stat'ed, falls back to the system temporary directory and the D-32 copy path, with its existing notice. The tree is
    never inside a corpus, and where it lies changes no output byte.
  - **Other paths checked; none needed a change:**
    - `derive --out` takes the user's NEW;
    - the derive, validate and import scratch stores only put bytes;
    - the importer's temporary AER is read back, never renamed;
    - `package` and the release builder copy no raw objects.
  - **Measured.**
    - `recompute --dry-run --jobs 3` links all 3,253 objects and copies none (before: copies all 3,253). Outputs stay
      identical: 3,243 identical, 0 unexplained.
    - The speed effect is negligible on these corpora:
      - the copy it saves is 49 MB here (223 MB on `agentdojo-upstream-2024-06-rg1`);
      - `RawObjectStore.put` writes cost the same on both volumes (5,000 puts: 7.9–9.9 s on each; fsync bound);
      - the end-to-end runs, taken at load average 26–35 with suites alongside, ranged 181–432 s per arm, too
        noisy to show it.
    - So this is a robustness change: hard links work again, and dry-run I/O stays on the `AGENTPROV_HOME` volume.
  - **Rejected:** a tree beside the source corpus. It would write inside `corpora/`.
  - **Class 0:** `cli/derive.py`, `corpus/verify.py` and `corpus/scratch.py` are outside every stage scope.
