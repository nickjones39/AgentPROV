- **D-703 (2026-10-22, `agentprov settings`; part of D-700).**
  - **What.**
    - `agentprov.settings` keeps `$AGENTPROV_HOME/settings.json` (`agentprov-settings/0.1`, mode 0600): strict reads,
      atomic writes under a resource lock (read-modify-write).
    - A closed schema (key patterns with types, bounds, choices and validators) covers dev-run defaults and the live
      caps, estimate defaults, compute defaults (per-command `--jobs`, queueing, preset), job retention, and
      `endpoints.<name>.base_url`.
    - A local base URL must be http(s) on loopback or a literal private IP (10/8, 172.16/12, 192.168/16, 100.64/10,
      fc00::/7), with no host names, user info, query or fragment. The LAN opt-in stays per run (D-698).
    - An unknown key or a refused value is exit 2. A stored value that no longer validates reads as unset and is
      listed as ignored.
    - `get` returns `None` for an unset key; precedence (flag > environment > setting > registry) is the caller's.
  - **CLI:** `settings list [--prefix] [--schema] [--format]`, `get KEY`, `set KEY VALUE`, `unset KEY`. Values go to
    stdout.
  - **Rejected:** keeping them in Qt's QSettings (unreachable from the CLI); free-form keys (the file would gather
    arbitrary data); storing secrets (keys stay in the OS keychain, D-702).
  - **Tests:** `tests/cli/test_settings_cmd.py`. The CLI contract gains APP_COMMANDS.
