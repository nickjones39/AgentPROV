- **D-394 (2026-10-14, core: control file; approved as direction 2026-10-14 by the user, relayed by the orchestrator session; build after the regeneration round).** A global writer option `--control-file PATH`, holding
  `{"format":"agentprov-control/0.1","request":"drain"|"stop","issued","nonce"}`.
  - **Polling:** the CLI checks it by `stat` at unit boundaries (≤ once per second inside long units) and echoes a
    `control` progress event.
  - **`drain`:** finishes in-flight units, flushes and exits with outcome `drained` (exit 0). It is resumable by
    re-running the same argv.
  - **`stop`:** behaves like the first SIGTERM on every OS. Windows has no graceful signal path today.
  - **Rejected:**
    - SIGSTOP/SIGCONT (wall-clock timeouts and paid HTTP calls keep running; no Windows equivalent);
    - signals only (not graceful on Windows);
    - stdin commands (no pipe may tie the job to the GUI);
    - sockets or named pipes (a server).
