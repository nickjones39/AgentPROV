- **D-392 (2026-10-14, GUI job manager; approved as direction 2026-10-14 by the user, relayed by the orchestrator session; build after the regeneration round).**
  - **Detaching:** jobs run as **detached** CLI processes:
    - POSIX: a new session;
    - Windows: `CREATE_NEW_PROCESS_GROUP | DETACHED_PROCESS | CREATE_BREAKAWAY_FROM_JOB`.
  - **Process environment:** stdout and stderr go to files, stdin is closed (or carries the keys once, D-395), and the
    environment is an allowlist.
  - **State:** each job has a directory `$AGENTPROV_HOME/gui/jobs/<uuid7>/` with `job.json` (argv, pid +
    `create_time`), progress, log, summary and control files.
  - **Lifecycle:** re-attach is from files; closing the GUI never stops a job.
  - **Serialisation:** one writer per corpus, plus global slots for `fetch`, `import --fetch` and `backends build`.
  - **Batches:** a batch queue (the regeneration round) that advances only while the GUI is open.
  - **Rejected:**
    - `QProcess` with pipes (the job dies or blocks with the GUI);
    - a scheduler daemon (a resident service);
    - a terminal multiplexer (not cross-platform).
