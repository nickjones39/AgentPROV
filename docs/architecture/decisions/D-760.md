- **D-760 (2026-10-22, user decision; session "user guide", phase 1b).** The user guide (`docs/user-guide/`) gets a
  website on GitHub Pages, built now and published only when the repository is made public.
  - **What.** `mkdocs.yml` at the repository root builds `docs/user-guide/` (and nothing else from `docs/`) with
    MkDocs 1.6.1 and Material for MkDocs 9.7.7, pinned exactly in a `docs` dependency group that a plain `uv sync`
    does not install. `strict: true`; no analytics, no Google Fonts (`theme.font: false`), no CDN, the built-in search
    only, and a theme override so the repository link never asks the GitHub API for facts from a reader's browser. Site
    address `https://nickjones39.github.io/AgentPROV/`; `site/` is git-ignored. Links to repository files outside the
    guide are absolute GitHub URLs (tested). `.github/workflows/pages.yml` runs only on `workflow_dispatch`, with
    `contents: read`, `pages: write`, `id-token: write`, and every action pinned by commit SHA (tested). Going live
    follows `docs/user-guide/_go-live.md`: the owner's instruction, the repository made public by the owner, the
    pre-release scans over the built site, Settings › Pages › Source "GitHub Actions" (by the owner), one dispatch,
    and a check of the live URL.
  - **Why this generator.** Material for MkDocs entered maintenance mode on 2025-11-11 (critical fixes for at least 12
    months, no new features) and names Zensical as its successor; MkDocs 1.x has had no release since 2024-08 and its
    2.0 rewrite breaks Material. The user chose the stable pair (2026-10-22): a static build of our own Markdown carries
    little risk from an unmaintained build tool, and Zensical (alpha, 0.0.x) reads `mkdocs.yml`, so the configuration
    stays within settings both understand and a later switch is a dependency change.
  - **Rejected:** a GitHub wiki (needs a paid plan for a private repository); publishing on Pages now (it would make the
    guide public before the repository is); Read the Docs or Cloudflare Pages (third-party hosts); Jekyll from `/docs`
    (it would publish the whole `docs/` tree: specification, reports and reviews); Zensical now (alpha, releases every
    few days, plugin parity unfinished).
  - **Downstream:** none for corpora or stage digests (class 0): `uv.lock` gains the `docs` group only, and no `src/`
    file changes.
