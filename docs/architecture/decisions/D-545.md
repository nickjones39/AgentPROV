- **D-545 (2026-10-14, GUI S11 tolerance for psutil's `socket` import; user decision 2026-10-15: approved; amends D-396 S11 like D-448).**
  `psutil` (design §2.2, D-392: job identity and the System tab) imports `socket` at module level for its
  address-family constants; it opens no socket. The fresh-interpreter S11 check therefore tolerates `socket` and
  `_socket` **only when their importer is `psutil`** (checked with an import hook in the test); the static bans in
  `gui/src` stay, and `ssl`, `http.client`, `urllib.request`, `asyncio`, `QtNetwork` and web views stay forbidden.
  - **Rejected:** dropping psutil (the pid-plus-create-time identity and the sampler need it, and re-implementing them
    per OS is larger and riskier); importing psutil lazily (the job manager needs it at start for re-attach).
