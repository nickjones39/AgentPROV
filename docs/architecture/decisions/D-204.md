- **D-204 (2026-10-12, deferrals part A: the member-origin interface for mappers; user-approved with the merge of part A; the mapper side is regen-batch item 18).**
  For an archive input, the `origin` a whole-file map job receives is a `member` origin `{container, label, method,
  crc32, size}`. Its `label` is the member's NFC name, the same string the profile's `include` globs and layout
  templates were matched against, so a mapper that reads a git origin's `path` for its layout (the TraceLogger mapper,
  `adapters/agentdojo/mapper.py`, locator `{"a": "a0", "o": "/path"}`) reads `/label` for a `member` origin (phase 10f
  routing F2). The runner change does not touch any mapper; the mapper change is the regen-batch session's and moves no
  stored AER (no stored corpus has a member-origin AgentDojo log).
