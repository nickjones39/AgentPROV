- **D-25 (2026-10-11, licence exclusion criteria for the systematic source search; user decision).** A source is
  converted only if its data is under a licence that permits redistributing derived data. Records with **no licence**
  (EX-LIC-1) and records whose licence **forbids redistribution**, including evaluation-only licences (EX-LIC-2), are
  excluded, however well their format fits. A repository-level licence that covers the data counts as a licence (MIT by
  repository for AgentDojo upstream, ROPE and AgentDyn). A use clause that still permits redistribution (AgentHarm) is
  included with the clause recorded (U-05). Copyleft and non-commercial licences permit redistribution and are
  included (user decision, same day): GPL-3.0 and AGPL-3.0 sources each become their own corpus under that licence,
  and CC-BY-NC sources go into a separate `-nc` corpus under the existing `nc_partition` policy. Every screened record, included or excluded, appears in the manuscript's
  included/excluded table with its licence and exclusion code. The full criteria are in
  `docs/reports/systematic-search/eligibility-criteria.md`. In the registry, an excluded record keeps the existing
  vocabulary (`reference`/`forbidden`, role `mirror`/`not_executions`); "excluded" is not a registry status (§I.0.2).
  - **Why:** a corpus built from data with no licence, or a non-redistributable licence, cannot be published or
    deposited, and a complete table makes the source selection defensible.
  - **Rejected:** converting unlicensed data for local analysis only (the results could not be reproduced from a
    published corpus); treating a missing platform licence tag as "no licence" without reading the LICENSE file or
    README (would wrongly exclude sources licensed at repository level).
