- **D-740 (2026-10-22, a per-cell call bound for Inspect cells under the D-725 caps; user-approved, option (a) of
  `docs/reports/inspect-harness/cell-bound.md`; class 0).** D-741 to D-749 are reserved with it; D-741 opens the
  `agentharm` · `live` gate, D-742 the Inspect preflight probe, D-743 the per-build Inspect model and errored-sample status, D-744 the probe in the caveat, and D-745 to D-749 are unused.
  - **Why.** D-725's worst case per cell is the AgentDojo cell's 48 calls. An Inspect cell is `cell_size` samples ×
    epochs, each with agent and judge calls, so capped Inspect runs were refused (D-667 addendum).
  - **Bound.** `n × E × ((M − 1) × (1 + a) + j) × (1 + K)` billed calls, from T0's own plan document:
    - at most `M − 1` agent calls per sample: Inspect 0.3.263 refuses a generate at the message limit;
    - `a` judge calls per agent call and `j` per sample, from the task's `InspectCallBound` in `cli/live/envs.py`
      `BACKEND_KINDS`. For AgentHarm `a = 1` (the refusal judge reads every assistant message) and `j = 3` (at most 3
      semantic-judge calls per grading function, none in a loop);
    - the bound is valid for the pinned code only (`task_files_sha256` `sha256:4ba500be…`, inspect_evals 0.20.0). The
      backend test re-derives `a`, `j` and the digest from the installed code;
    - `K = 1`: the worker sets Inspect's `max_retries=1` for the agent and every judge and turns the provider SDK's own
      retries off (`max_retries=0` model arg), because Inspect retries an empty 200 stream and timeouts, which D-725
      counts as billed. This is `inspect.harness_settings@2`.
  - **Refusals** (`cli.refused.api_caps`, exit 4):
    - a task without a bound, or with other task code;
    - a judge on another model than the agent (the caps have one price pair);
    - a plan without its message limit, epochs or cell size.
  - **Cells.** Under caps an Inspect plan defaults to `cell_size = 1`, so a cell reserves one sample's worst case and
    the recorded spend decides whether the next one starts. `Budget.cell_calls` replaces the constant in the start
    check and in `cap_bound_exceeded`, and `live.caps.cell_call_bound` records the bound used. AgentDojo-family runs
    are unchanged.
  - **The probe** (D-667, the user's typed yes on 2026-10-22, run after the round):
    - 4 AgentHarm samples, agent and judges gpt-4o-mini, `--max-cost-usd 0.50`;
    - `--cell-size 1`, `--message-limit 10`, `K = 1`;
    - each cell reserves 42 calls, about $0.305 at $0.15 in and $0.60 out per million tokens.
  - **Rejected:**
    - a token-limit-based USD bound for now (it needs a check of what Inspect counts against `token_limit`;
      cell-bound.md section 5);
    - per-role price flags (possible later if a judge model must differ).
