- **D-460 (2026-10-14, `aer.rules.drift`: corpora built while a catalogue was edited in place; follow-up of D-430,
  approved by the user 2026-10-14).** Between `afe7038` (which built every stored corpus) and the D-31 bumps
  (`430a2dc4`), catalogues were edited in place at version 1. A corpus imported in that window records, for example,
  `agentdojo` 1 with bytes that differ from the archived v1, and its AERs cite rules that v1 lacks. On main, `validate`
  then failed every row with `aer.rule.missing` and `aer.rule.class`, and tier 4 with `pv.linkage.method`: wrong
  findings for a version problem. The one known case is pipeline-perf's scratch Mandate import at `8e6d632f`.
  - **Rule:** `corpus.authority.catalogue_drift` lists the `aer` stage catalogues recorded at a shipped version whose
    `derivation.json` digest differs from the package bytes. Each one is reported once as `aer.rules.drift` ("built
    against catalogue bytes that differ from the shipped vN; check at the building commit"), in place of
    `rules.mismatch`:
    - **`validate`:** one notice per catalogue, the counter `rules_drift`, `issues_by_code`. Every row whose AER
      declares that version gets the single failing check `aer.rules.drift`; its AER-rule, SEM and tier-4 checks do
      not run.
    - **`verify`:** chain reports it as failed. `rederive` does not re-derive, and reports `rederive.unavailable`
      (unverified) per catalogue.
    - **`recompute`:** it is a D-430 drift line. A dry run reports it; `--out` refuses.
  - **Unchanged:** a swapped `rules/` copy or source or semantics profile digest is still `rules.mismatch`; the round's
    fresh re-imports are not affected; no AER, SEM or PROV bytes move. Tests: a drift-window fixture (the AERs resealed
    to declare `agentdojo` 1, the recorded digest set to today's bytes), shown to give the per-rule errors without the
    gate.
  - **Rejected:** keeping the per-rule errors and adding a note (they are wrong, not just noisy); loading the recorded
    bytes from the corpus `rules/` copy (AD-14: the package is the authority, a copy is a record).
