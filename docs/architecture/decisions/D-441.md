- **D-441 (2026-10-14, GUI main-executable SDK; user decision 2026-10-14: approved as direction).** The macOS release
  bundle's main executable (PyInstaller bootloader or launcher) is linked against the current macOS SDK (≥ 26). Without
  that, AppKit and Qt draw the compatibility look: the uv CPython 3.14.8 is SDK 15.0 (measured M1/M2).
  - The build checks the SDK with `otool -l` and, if needed, rebuilds the bootloader from source on the build Mac.
  - An optional development launcher (`Py_BytesMain`, about 30 lines) gives the current look under `uv run`.
  - Qt ≥ 6.12.1 on macOS 27 (QTBUG-150017).
  - **Rejected:** accepting the compatibility look; the `UIDesignRequiresCompatibility` opt-out (honoured only on macOS
    26).
