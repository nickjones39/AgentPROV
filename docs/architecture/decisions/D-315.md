- **D-315 (2026-10-14, RW-1 follow-up: objects that hold the same bytes are withheld together; F-1 of ingest-formats-3
  nested-design.md §8 and the carved-blob case; user-approved 2026-10-13, (d) added 2026-10-13).** The planner's
  container closure (AD-12, D-232) follows two more links, both ways, each closing to a fixed point with basis
  `container`, the reason of the object that set it off, a generated note, and no affected execution:
  (a) a withheld split descriptor (D-244, D-249) withholds every byte part its `split` origin lists; (b) a withheld
  part withholds its descriptor and so the other parts; (d) a withheld carved blob (D-218) withholds the object it was
  carved from, and a withheld source withholds every blob carved from it. Members of a withheld descriptor stay
  released (D-232), and executions are withheld only by their own causes (a derived hit still withholds one, D-235).
  (c) `chain` fails a `WITHHELD.json` that lists some but not all of a group: `withheld.split_part` for a split archive,
  `withheld.carved` for a carved pair (the deposit builder runs `chain`). The links are read from `raw/origins.jsonl`
  (`agentprov.corpus.withhold.linked_objects`), which sealing keeps whole (D-231), so `chain` re-checks them offline.
  - **Why:** the probe on a real split-zip import (FooBench, five 1,500 B parts, a marker in one member) withheld the
    member and the descriptor but only the one part whose stored bytes held the marker verbatim; with deflate
    (control-arena) no part. A carved blob holds a value its source may carry only in another encoding (base64), so a
    pattern can hit one and miss the other.
  - **Digest effect:** sealing only; no AER, SEM, PROV or validation digest moves and `recompute` is unaffected. A sealed
    tree changes only when a corpus has a split input or a carved blob and withholds something linked to it; no stored
    or sealed corpus has either yet (control-arena is not imported; no mapper carves, regen-batch item 29).
  - **Rejected:** withholding only the parts or blobs a rule hits (deflate and encodings hide the bytes: the probe);
    keeping parts released because the descriptor is withheld (the parts are the bytes); a new basis `split` or
    `carved` (the frozen `withheld-0.1` BASES enum, D-163; `container` already means "holds a withheld object's bytes");
    withholding a descriptor's members too (they are their own objects with their own causes, D-232).
