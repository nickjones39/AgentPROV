- **D-946 (2026-10-29, licence classes for the 145 unclassified fixture entries, the U-06 follow-up that D-943 names:
  "the 145 unclassified entries are classified first and follow their class"; addendum to K.4.1(1) and K.4.2; byte
  class 0).** Before this change, 145 `SOURCE.json` entries had no `licence_class`: `agentops` 25, `autogen` 9, `drift` 9,
  `mcphunt` 1, `memo-ozdincer` 3, `wirelog` 98. Under D-943 they stayed private and out of the snapshots.
  - **Decision.** All 145 are `permissive` with `synthetic: false`. Each entry's origin fields name its profile's pin:
    the container sha256 for the Zenodo zips and tarballs, the repository and revision for the git and Hugging Face
    origins. Each profile's `[licence]` table declares a permissive basis with `policy = "include"` and no
    restrictions: Apache-2.0 (AgentOps-Bench), CC-BY-4.0 data with MIT code and third-party parts (AutoGen guard
    placement), MIT at the head pin (DRIFT), CC-BY-4.0 (MCPHunt), MIT at the pin (memo-ozdincer), and CC-BY-4.0 under
    LICENSE-DATA (What-Surrounds). The pre-check research records agree. For DRIFT, K.4.2 already classes HEAD blobs
    `permissive` and history-only blobs `restricted`. All 9 fixtures are blobs of the head pin `6fd3df47`, and none
    comes from the `history` pin. No entry was undecided. The wirelog fixtures are all members of the What-Surrounds
    deposit, so none is synthetic. The MCPHunt fixture is a derived set of record slices in a project-written
    envelope: real data, so not synthetic.
  - **`synthetic` everywhere.** The 22 classified real entries without the field (`credleak` 11, `seagent` 10,
    `inspect/whistlebench` 1) get `synthetic: false`. Every entry of the tree (72 files, 949 entries) now records it.
  - **Guard.** `tests/golden/test_fixture_licence_classes.py` fails when an entry lacks a boolean `synthetic`, or when
    a real entry lacks a class from the closed set. It also pins the 145 classifications. The fixture generators that
    write these `SOURCE.json` files (`tools/agentdojo/phase10q_fixtures.py`, `phase10f_fixtures.py`,
    `tools/credleak/build_fixtures.py`) emit both fields.
  - **Evidence and gaps.** `docs/reports/release/u06-fixture-classes.md` gives a table of source × entries × class ×
    evidence. It also lists two notice gaps for the public export: no source-specific licence text exists under
    `tests/fixtures/LICENSES/` for DRIFT or MCPHunt (K.4.2). Model-provider terms stay "not assessed" (D-943).
  - **Bytes (class 0).** Only fixture metadata changed: 9 `SOURCE.json` files (+8,537 B), all within the
    `tests/FIXTURES.json` caps. No fixture data file and nothing under `src/agentprov` changed. No stage scope covers
    the fixture tree.
  - **Rejected.**
    - Leaving the 145 unclassified so that the export excludes them: the evidence is complete and permissive, and D-943
      asks for classification.
    - Classing per source in a side table instead of per entry: the export and the snapshot tool (D-942 S-4) read each
      entry's own `licence_class`.
    - Classing DRIFT `restricted` as a whole: K.4.2 separates head blobs (MIT) from history-only blobs, and every
      fixture is a head blob.
