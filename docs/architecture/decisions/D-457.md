- **D-457 (2026-10-15, bug pass bugpass-perf-10: the release scan reports third-party account paths; user decision
  2026-10-15: approved).**
  - **Context:** `tools/release_scan.py` searched only for the operator's own home path and host name (R-51, rules
    `home-path` and `host-name`; inside archives since D-491). The corpus pre-check found a third-party workstation
    account path in 24 raw-store context artefacts (`run_manifest.json`) of `interbolt-agentdojo` (PC-05, CC-11), in no
    AER, SEM or PROV statement. The release scan would have passed them with no finding. The user decided on
    2026-10-15 that account or workstation paths in raw-store context and auxiliary files are security findings: they
    are triaged before a deposit and withheld (`personal_data`) where they identify a person (D-456 withholds the
    interbolt files).
  - **Decision:**
    - A new rule `account-path` in the path scan, over every file it reads: every raw-store object (context and
      auxiliary files included, binary or not) and the decoded unselected archive members (D-491, same locators and the
      same fail-closed `home-path-unscanned` finding). The path scan becomes version 3.
    - Forms (bytes, case-sensitive unless stated): `/Users/<name>`, `/home/<name>`, their JSON forms with an escaped
      slash `\/Users\/<name>` and `\/home\/<name>`, `C:\Users\<name>`, its JSON-escaped form `C:\\Users\\<name>`,
      `C:/Users/<name>` (any drive letter, either case; `Users` in any case) and `/mnt/<drive>/Users/<name>` (WSL).
      `<name>` is `[A-Za-z0-9._-]{1,64}`, so a match is bounded and never backtracks badly.
    - Ending: the name is followed by a separator (`/`, or `\`, which also opens a JSON escape such as `\/`, `\"` or
      `\n`), a closing quote (`"`, `'`), whitespace, `,`, `:`, `;`, `)`, `]`, `}`, a NUL or the end of the file
      (the scan reads a file's last bytes once more with a NUL after them). So a bare home (`"HOME": "/Users/<name>"`,
      `HOME=/home/<name>` at the end of a file) is reported. Trailing dots are ignored for the allowlist and the
      operator check (`/home/user.` ends a sentence).
    - Speed: the search finds the literals `users`, `/home/` and `\/home\/` and matches anchored at them (some 100 to
      350 MB/s on JSON, plain or with escaped slashes).
    - Boundary: `/Users/` and `/home/`, and the escaped `\/Users\/` and `\/home\/`, must start an absolute path (not
      preceded by a letter, digit, `.`, `_` or `-`). `https://example.com/home/page/` (escaped or not) is not reported;
      `file:///Users/x/` and `"/home/x/` are.
    - Not covered: deeper roots that the boundary excludes, such as `/var/home/<name>` (Fedora Silverblue) and
      `/System/Volumes/Data/Users/<name>` (the macOS data volume), and the WSL form with escaped slashes.
    - A finding is untriaged and holds the path, rule and line only (`<path>:account-path:<line>`), never the name,
      the match or the line text.
    - Triage reuses the existing values (no new value, so `agentprov.release` is unchanged): `real` for a path that
      identifies a person (withheld `personal_data` in a new version, so `WITHHELD.json` names it), `synthetic-benchmark`
      for a made-up benchmark account, `false-positive` for text that is no account path.
    - The operator's own home path, when it is `/Users/<name>` or `/home/<name>` written unescaped, bare or not, stays
      `home-path` only. The same name in a Windows or `\/`-escaped form is an `account-path` finding, because
      `home-path` does not see it.
  - **Allowlist:** `ACCOUNT_ALLOWLIST` (a frozenset in `tools/release_scan.py`, compared case-insensitively), names
    that identify nobody: `user`, `users`, `ubuntu`, `runner`, `runneradmin`, `root`, `shared`, `guest`, `vscode`,
    `codespace`, `jovyan`, `ec2-user`, `admin`, `administrator`, `default`, `public`, `travis`, `circleci`,
    `appveyor`, `vagrant`, `docker`, `app`, `node`, `nobody`, and the placeholders `<user>`, `<username>`, `username`,
    `$user`, `%username%`, `you`, `me`, `name`, `example`. Placeholders with characters outside the name class never
    match it; they are listed so that the list stays right if the class is widened. Names made of dots only (`..`) are
    not reported either.
  - **Rejected:**
    - keeping the operator-only search (it cannot see anyone else's account, the interbolt case);
    - no allowlist (CI and container paths such as `/home/runner/` and `/Users/runner/` would flood the triage and
      hide the identifying few);
    - withholding automatically from the scan (the scan is a report outside `src/`; whether a path identifies a person
      is a human triage decision, and withholding belongs to sealing, H.4.5).
  - Byte class 0 (`tools/` and docs).
