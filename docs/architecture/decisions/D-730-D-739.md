- **D-730..D-739 (2026-10-22, API providers' model lists; user requirement relayed by the orchestrator, the "auto once a
  day" choice the user's).** Models change often, so the picker must always offer a working list.
  - **D-730, the command.** `agentprov models --endpoint <openrouter|anthropic|openai|deepseek|gemini|llama|qwen|glm>`
    shows the provider's model list (`agentprov-provider-models/0.1`): from the dated cache by default; fetched now
    with `--allow-network` (R2). Endpoints: OpenRouter `GET /api/v1/models` (public; a key is sent only when given
    explicitly), Anthropic `GET /v1/models` (`x-api-key`, `anthropic-version: 2023-06-01`, paged by `after_id`, at
    most 10 pages of 1000), OpenAI `GET /v1/models` and DeepSeek `GET /models` (Bearer key). `gemini`, `llama`, `qwen`
    and `glm` are OpenRouter shorthands: OpenRouter's list filtered by vendor prefix (`google/`, `meta-llama/`,
    `qwen/`, `z-ai/` + `thudm/`; a table in `cli/live/providermodels.py`, not `endpoints.toml`, so no env rebuild).
    List calls only: no tokens, no cost.
  - **D-731, network and data rules.** The registry host only (never a `.env` base URL); `http.client` over HTTPS with
    the default TLS context; no proxy; no redirect (only HTTP 200 counts); 20 s timeouts; 16 MiB per body; strict JSON
    through `agentprov.ingest`; checked members only (ids are labels; OpenRouter prices decimal strings). Keys never
    come from argv. **Order (user decision 2026-10-22): the OS keychain is the source of truth** (D-702); with no option
    the keychain is read first and the default `.env` only when the keychain holds no such key or cannot be read;
    `--keychain` reads only the keychain, `--env-file` / `--env-stdin` only those. The source used is a notice, never
    the value. Keys are registered for redaction before any request and travel only in their header; a keyed provider without a key is
    refused before any request (exit 3). **Rejected:** `urllib` (honours proxy variables); a key on argv.
  - **D-732, the cache.** `$AGENTPROV_HOME/models-cache/<endpoint>.json`, written atomically: endpoint, host,
    `fetched_at` (ISO UTC, this machine's clock at the fetch), each response's sha256, the rows (ids and metadata
    only). Shown with its date; `stale` after 24 h. A failed refresh shows the cached list with `refresh_error`; with
    no cache the list is empty (`source: "none"`); nothing is invented. A damaged cache is ignored, never half-read.
  - **D-733, auto refresh (the user's standing consent).** The setting `models.auto_refresh` (D-703 store; bool, off
    until the user switches it on). When on, `agentprov models --refresh-if-stale` (and the GUI's Run live, which
    calls it) fetches a configured provider's list when the cached one is older than 24 h, at most once a day.
    **Enabling it is the user's standing consent for these free list calls only** (no other network call, no model
    call, no cost). With the setting off, `--refresh-if-stale` only reads the cache and says so.
  - **D-734, run warning.** `run` with a provider endpoint reads that provider's cached list (no network): a requested
    model it does not list is a warning before the run, never a refusal (lists lag). The served model is still
    recorded and compared (A12).
  - **D-735, prices.** Each listed model carries `price_status` from the D-701 price table (`lookup`): `priced` or
    `no_price` (the estimate then needs a price override); priced models the provider no longer lists are reported as
    `not_listed` (`models_for` minus the price-table names the listed models are priced under: a dated Anthropic id
    priced by its alias, D-701 follow-up, covers that alias and carries `priced_as`). The CLI and the GUI read the same document.
  - **D-736:** its own entry (local model identity without load state). **D-737..D-739** reserved.
  - **Class 0** (cli/, formats, tests, the GUI's `models` form): no capture, backend, AER, SEM or PROV change.
