- **D-440 (2026-10-14, GUI toolkit for a native macOS feel; user decision 2026-10-14: approved as direction; amends
  D-390).** PySide6 6.12 / Qt Widgets stays the toolkit on macOS, Windows and Linux. On macOS a **native chrome layer**
  is added through PyObjC (MIT): `pyobjc-core`, `pyobjc-framework-Cocoa` and `pyobjc-framework-UserNotifications`, as
  darwin-only dependencies of `gui/`, pinned in `gui/uv.lock`. All PyObjC use is confined to
  `agentprov_gui/platform/macos.py`. The layer provides:
  - a real `NSToolbar` (unified, Liquid Glass groups, title and subtitle, `NSSearchToolbarItem`) whose items call the
    same `QAction`s as the menus;
  - Dock tile progress;
  - `UNUserNotificationCenter` notifications;
  - the standard Window-menu actions;
  - the Reduce Transparency and Differentiate Without Colour flags.

  If the module or its smoke check fails, the GUI falls back automatically to the Qt toolbar (a setting, and
  `AGENTPROV_GUI_NATIVE_CHROME=0`).
  - **Evidence:** a Qt window with the native toolbar closely matches a SwiftUI reference (macos-design §2.1, M4 against
    M5). Tuned Qt alone reaches only the macOS 14–15 look (M3).
  - **Rejected:**
    - a SwiftUI or AppKit front-end beside Qt: two view layers; the security layer ported to Swift; full Xcode needed
      (M6); a macOS-only test stack while CI is dispatch-only (D-431); the M10 spawn risk;
    - a Swift front-end over a Python view-model helper: still two view layers plus an IPC protocol. Kept as the
      re-evaluation option;
    - a PyObjC AppKit front-end: rewrites every data source and the graph canvas;
    - wxPython: no virtual list on macOS; no Linux wheels; `wxAccessible` is MSW-only;
    - Toga: bulk-update issue #2747 is open;
    - Compose Multiplatform, Avalonia and .NET MAUI: not native on macOS; not Python; MAUI has no Linux;
    - Qt only: no glass toolbar, no Dock progress, deprecated notifications.
  - **Re-evaluate** if a Qt release breaks the toolbar attachment without a fix within one patch release, or if Qt ships
    public `NSToolbar` or glass APIs.
