  decision 2026-10-14: option (i) approved, (ii) rejected).**

    basis `unscanned`, reason the policy's reason. A new ledger version `agentprov-withheld/0.3` and its schema file
    carry the new basis; `/0.1` and `/0.2` are unchanged (D-163). `chain` and the builder accept it.
  - **Spread:** AD-12 closes it over the archives that hold it, at object level only. The good members, stored as
    objects of their own, and their executions stay released.
  - **Reporting:** the seal report prints the count and the container chain loudly.
  - **Sequencing:** built with or before D-453; until then an unreadable archive refuses the seal (D-450).
  - **Rejected:**
    - (ii) an identity rule in `[withhold]` (objects by digest or member label): every residual would have to be listed
      by hand, a version bump of each such profile is needed, and a missed one still refuses (maintenance cost and
      miss risk);
    - refusing for ever (a source with one unreadable file could never be sealed);
    - releasing unread bytes.
  - **Built (2026-10-21, branch `bugpass-d453-d454`).** `withheld.py`: `FORMAT_03`, `BASES_03` (`unscanned` last, so

    `unscanned`. `withhold.py`: the planner adds the cause with `UNSCANNED_NOTE` and the byte rules' first reason, then

    `withheld_unscanned` and a notice starting `WITHHELD UNREAD`. `chain` and the builder need no change: they rescan
