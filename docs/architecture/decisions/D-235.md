- **D-235 (2026-10-12, withholding: object-level and execution-level withholding; user-approved 2026-10-13).** Object scope withholds a
  raw object while the executions that cite it stay released, for the case where their derived records never held
  the value (DTap's `env_vars`, which the mapper never reads). Such an execution's AER still names the object in
  `artifacts[]`; `chain` counts it as withheld (`raw_withheld`) instead of missing. If a derived file of such an
  execution hits a rule anyway, the execution is withheld too, so the scope claim is checked, not trusted.
  - **Rejected:** always withholding the citing executions (it would drop executions that hold no value, e.g. DTap's
    4,139); never escalating an object-scope hit (it would trust the profile's claim).
