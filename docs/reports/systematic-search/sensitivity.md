# Systematic source search: size-threshold sensitivity

Status: 2026-10-11, updated 2026-10-12 with the phase-10e verification. Required by D-25 and `eligibility-criteria.md` (size criteria, disclosure). The size thresholds were set after the known sources had been identified, so this table shows the included sources and their distinct runs under no threshold and under uniform thresholds of 100, 1,000 and 5,000 runs, beside the adopted two-tier rule (EX-SIZE-1: fewer than 100 runs for any source; EX-SIZE-2: fewer than 1,000 for a source that needs a new adapter family). Generated by `scripts/merge_screen.py` from the strand records under `data/`; regenerate rather than edit by hand. Names, URLs and notes are third-party data, reduced to printable ASCII, with `|` escaped.

Current corpora and candidates are shown separately. A threshold T keeps a source with at least T distinct runs. Runs: a plain number is exact (verified count or full census); `>=N` and `<=N` are verified lower and upper bounds; `~N` is an estimate from a listing, a paper or deposit metadata; `(N files)` is a file count from a listing, not a run count; `?` is unknown.
