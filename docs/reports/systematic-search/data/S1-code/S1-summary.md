# S1 summary: systematic search, code platforms

Search run 2026-10-11 (UTC), read-only (`gh api` GET, GraphQL queries, HF/GitLab/Codeberg/Zenodo public JSON APIs, web search/fetch). Nothing was cloned, starred, forked or downloaded; sample files were read only to identify the schema (a handful of files under 1 MB). Third-party README/CLAUDE.md text was treated as data. Full query list: `S1-search-log.md` / `S1-queries.jsonl`.

## Files
- `S1-search-log.md`, `S1-queries.jsonl`: every query/endpoint with platform, exact string, UTC time, result count, screened, retained.
- `S1-records.jsonl` (248 candidates; fields as requested plus `licence`, `licence_source`, `conversion_status` {included, pending, excluded}, `exclusion_reason`, `found_by_search` for known items).
- `S1-included-excluded.csv`: flat table of the same records for the appendix.
- `S1-forks.jsonl` (all 243 forks), `S1-dependents.jsonl` (3,192 repositories found in step 2, with screening results).

## Known sources: did the search find them?
All 14 known items (13 listed + ADI) were found by at least one search path (see `found_by_search` in records). Note also: upstream and the NIST fork were found by repo and code search; AgentDojo-PROV was found on GitHub and Zenodo.

## Could not be accessed / limitations
- GitHub search caps at 1,000 results/query; "from agentdojo" and some README queries exceed it (partitioned by size, not exhaustive). Dependency graph shows only ~49 of ~60 dependent repositories through the web fetch tool.
- One primary rate-limit stop on the shared GitHub token (about 07:20Z); queries were retried and failed attempts removed from the log.
- HF gated/401 datasets (SafeArena env, CIAware-Bench-Data, several guessed names) not readable; Zenodo zip contents and all HF datasets were not downloaded, so format "unclear" means not sampled. tau2-bench result files (>5 MB) were not sampled. SWE-bench and OSWorld trajectories are hosted off GitHub and were not located.
- Novelty is judged by blob SHA against upstream HEAD, 30 historical upstream commits and the 7 known repos; unseen older upstream commits could still make a few copies look novel (path collisions with upstream were excluded).
- 124 records are "unclear" because format was not sampled; 21 forks/dependents that are only copies of known runs are not records (see `S1-dependents.jsonl`).
