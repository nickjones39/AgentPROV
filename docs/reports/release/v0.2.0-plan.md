# AgentPROV v0.2.0: release plan

Date: 2026-11-05 (NZDT). v0.2.0 carries the GUI redesign and the 0.2.0 change batch, whose fixes change what a
re-import of a source produces, so it is a minor release, not a patch. The v0.1.0 plan (`v0.1.0-plan.md`) and the
v0.1.1 plan (`v0.1.1-plan.md`) are the models; this plan lists only what differs from v0.1.1.

## What is in it

| Change since v0.1.1 | Where |
|---|---|
| One visual and form style for the whole desktop app, the three-pane Viewer, tooltips | D-1060; `gui/` |
| Run Live's cost quote, local priors (`agentprov priors`), daily price refresh | D-1062; `src/agentprov/estimate/`, `gui/` |
| Pause, Resume, Stop and Cancel of a live run; Stop for dev runs and batches | D-1061; `cli/jobs`, `gui/` |
| The Assistant as a tab beside the page, and knowing which page that is | D-1040, D-1041; `gui/`, `agentprov assist` |
| The 0.2.0 change batch: every recorded corpus-affecting finding fixed, with the D-31 version bumps | D-1063; regen-batch rows 173 to 186 |
| `recompute` / `verify --level rederive` exit codes; derived corpora not sealable | D-1050, D-1051 |
| Windows platform limits: refused with the reason, disabled in the app | D-1064; `agentprov.platforms`, `gui/` |
| Check for Updates (`agentprov update`), and `release.yml` signing `SHA256SUMS` with the release key | D-1065; `src/agentprov/update/`, `.github/workflows/release.yml` |
| Sealed corpora read-only; a LAN model server stays class `api` | D-1066, D-1067 |
| Pipeline performance, class-1 items | D-1068; regen-batch row 187 |
| `validate --corpus` skips the checks that need withheld raw objects | D-1069 |

Unlike v0.1.1, files under `src/agentprov/{aer,sem,prov,views,validate,corpus,raw,ingest}`, the adapters and
`capture/` change. The sealed corpora are **not** rewritten or re-deposited: each stays derivation-reproducible at the
commit that built it (F-8), and a `recompute` at 0.2.0 of a corpus built before it is a drift report (H.8.4(5)). The
pipeline format ids are unchanged (`aer/0.2`, `sem/0.1`, `capture/0.1` with the C.13 amendment, `agentprov-prov/0.1`,
`apv 0.2.0`, `agentprov-corpus/0.2`); the catalogue and profile versions move as the release notes' table lists.

**Backend environments.** The live-capture fixes (regen-batch rows 177 and 184: the executor-gate recorder, defence
loading, the capture writer, Anthropic thinking sessions, usage counts) reach live runs only through rebuilt backend
environments. Before any live run uses them, rebuild them with `agentprov backends build` (it downloads the pinned
wheels, so it needs your yes); the release notes tell users to do the same after upgrading.

## The bundles (D-1011)

Built by `bundles.yml` at the tag, never from the development tree. Each leg runs `gui/tools/build_bundle.py`: the
build-time checks and an automated `--smoke` start of the GUI and the preview helper. They are built natively, none
under emulation. The 0.2.0 desktop app was tested on macOS; the G5 clean-machine runs (the nine steps on fresh VMs) were
made with 0.1.0 and are not repeated for 0.2.0, and the release notes say so.
