# AgentPROV v0.1.1: release plan

Date: 2026-11-01. The user's request: "can we do this as a release 0.1.1?" (building the bundles through GitHub instead
of emulation), "and we can include the new docs window and chatbot with this release too?", "Keep 0.1.1" (over 0.2.0,
which the new command would suggest under semantic versioning), and "can we also build a macos intel version". The
v0.1.0 plan (`v0.1.0-plan.md`) is the model; this plan lists only what differs.

## What is in it

| Change since v0.1.0 | Where |
|---|---|
| Help › Docs (the user guide in the app) and Help › Assistant (a chat through `agentprov assist`), Settings › Assistant | D-1010; `gui/`, `src/agentprov/cli/assist.py`, `cli/live/assistant.py` |
| The Zenodo uploader retries a file upload that fails in transit | `zenodo/` (`c3d5931e`) |
| Six bundles, each built natively on a GitHub-hosted runner of the public repository; a new macOS Intel bundle | D-1011; `.github/workflows/bundles.yml` |
| The landing page's app tour on phones, and its copy | `site/` |

No file under `src/agentprov/{aer,sem,prov,views,validate,corpus,raw,ingest}` or `capture/` changes, so no corpus
format, spec axis or derivation changes: the sealed corpora stay `v0.1.0`, and `recompute --dry-run` at R is unchanged
by construction (no corpus is re-deposited).

## The bundles (D-1011)

Built by `bundles.yml` at the tag, never from the development tree. Each leg runs `gui/tools/build_bundle.py`: the
build-time checks and an automated `--smoke` start of the GUI and the preview helper. They are built natively, none
under emulation; the G5 clean-machine runs of v0.1.0 (the nine steps on fresh VMs) are not repeated for v0.1.1, and the
release notes say so.

| Bundle | Runner |
|---|---|
| `AgentPROV-macos-arm64.dmg` | `macos-15` (Apple silicon) |
| `AgentPROV-macos-x86_64.dmg` | `macos-15-intel` (new in v0.1.1) |
| `AgentPROV-windows-x64.zip` | `windows-latest` |
| `AgentPROV-windows-arm64.zip` | `windows-11-arm` |
| `AgentPROV-linux-x86_64.tar.gz` | `ubuntu-22.04` (glibc 2.35 floor) |
| `AgentPROV-linux-aarch64.tar.gz` | `ubuntu-24.04-arm` (glibc 2.39 floor) |
