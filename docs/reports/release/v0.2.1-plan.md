# AgentPROV v0.2.1: release plan

Date: 2026-11-06 (NZDT). v0.2.1 is a patch release after v0.2.0 (published 2026-11-05, release record `48d25472`): the
desktop-app fixes and additions made after 0.2.0 (D-1070, D-1090, D-1120 and smaller fixes), the CI shard changes
(D-1100, D-1110) and the 0.2.0 release CI findings (D-1080, D-1081). The v0.2.0 plan
(`v0.2.0-plan.md`) is the model; this plan lists only what differs. **Nothing is published without your explicit yes
for that step** (the Yes column).

Two class-1 changes are in this patch release by your decisions of 2026-11-06. Regen-batch row 189 ("Keep it, patch
0.2.1") moves the `aer` code digest of every family and the `validation` code digest (`host.py` is in the AER stage
closure, `validate/cache.py` in the validation scope), and no AER, SEM, PROV or report byte. Row 190 ("Fix it in 0.2.1",
a fuzz finding of the release CI) moves the adprov adapter's code digest and no record of a well-formed transcript. No
sealed corpus is rewritten or re-deposited; the format ids, catalogue, profile and vocabulary versions do not move.
