# D-41: `sources[].lineage` is the profile's `[lineage]` table verbatim; the `duplicates` summary shape (phase 11, U3)

Status: implemented on branch `phase-11-u3` (U3), for consolidation into DECISIONS.md by the orchestrator.
Code: `src/agentprov/corpus/package.py` (manifest `sources[].lineage`), `src/agentprov/corpus/manifest.py`
(`duplicate_summary`, `LINEAGE`, `DUPLICATES`). Tests: `tests/unit/corpus/test_package.py`,
`tests/unit/corpus/test_manifest_schema.py`.

## Decision

1. **`sources[].lineage`** is the source profile's `[lineage]` table, copied verbatim (an object with the profile
   schema's keys `built_on`, `vendored`, `duplicates`, `cited_by`, `content_dedup`, `owns`, `excludes`; each
   `duplicates` entry `{of, part?, path, relation, owner}` with `relation` in `byte_identical | replicate | mirror |
   derived_conversion`). Lineage is declared once, in the owner profile (R-45, H.7.3, Q.29); the manifest records the
   declaration the build used, and the profile's own bytes are in `rules/<profile>.profile.toml`.
2. **`sources[].mirrors`** is `[]` in v0.1: the profiles declare mirrors as `[lineage].duplicates` entries with
   `relation = "mirror"` (e.g. AgentDojo-Inspect in `agentdojo-upstream`), which carry no pinned `Origin`; they are read
   from `lineage`.
3. **`duplicates`** (H.2.2 `DuplicateSummary`, which H.7 leaves unshaped) holds computed tallies only:
   `{content_dedup: "never", collapsed, multi_origin_executions, multi_snapshot_executions, owned_elsewhere}` =
   the `dedup.collapsed` register entries, the index rows with `n_origins > 1`, the rows with more than one snapshot,
   and the `select.owned_elsewhere` register entries. `content_dedup` is `never` in v0.1 (AD-10 row 7).

## Why

H.2.3 asked for an array of `LineageDecl`, but the profiles (the single place lineage is declared) hold the richer
`[lineage]` table; converting it would invent `basis` and `ev` values that the profiles do not record (invariant 2).
The duplicates tallies are what `verify --level chain` can recompute from the index and the register.

## Rejected

- Converting `[lineage]` into `LineageDecl` objects (fields not recorded; a second, lossy form of the declaration).
- Repeating the declared duplicates inside `duplicates` (a second copy of `lineage.duplicates`).
- Content-based duplicate counts (fingerprint deduplication is deferred, AD-10 row 7).
