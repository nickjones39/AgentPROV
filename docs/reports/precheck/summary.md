## Statistics and manuscript notes

Conventions the statistics owner must state wherever the numbers are used (routed via the orchestrator).

- **SN-01** (agentdojo-upstream (and every AgentDojo-format corpus with run errors)): Attack success rate convention for run errors. AgentDojo imposes outcomes on runs that end in a harness error (agentdojo.run_error_imposed_outcome@1; security = true). Counting them, as the AgentDojo results page does, reproduces its ASR for command-r-plus, gemini-1.5-pro-001, gpt-3.5-turbo-0125 and Llama-3-70b; the papers exclude them. Every ASR or utility statistic over AgentDojo-format corpora must state whether imposed run-error outcomes are counted, and report the count excluded. Source: docs/reports/precheck/agentdojo-upstream.md PC-02; orchestrator 2026-10-15.
- **SN-02** (agentdojo-upstream, ast-survey-agentdojo, mandate-agentdojo-eval): Benchmark checker validity: AgentDojo #181 (banking injection tasks count any transfer to the attacker IBAN) and #161 (Mandate user_task_5 always true) bias the logged booleans. Source: docs/reports/precheck/ast-survey-agentdojo.md PC-04; mandate-agentdojo-eval.md PC-01, PC-02.
