# `agentprov-prov/0.1` derive scan (phase 5, 2026-10-08; rerun after EF E.10 item 21)

`derive-scan.json` is written by `tools/prov/derive_scan.py`. The tool maps every baseline v1 transcript of
AgentDojo-PROV @ `579a908` with the `adprov-v1` profile, validates the AER and derives canonical PROV-JSON. The report
holds numbers only. It is a robustness scan, not gate D: tier-4 validation of the full trees is the phase-13 gate
(J.3.5). Derive latency was measured on an M2 Max with 10 worker processes and is indicative only.

Notes:
- The converted core holds fewer `llm → tool` communications than tool executions. In 2,799 converted executions,
  the call↔result link is positional (`agentdojo.positional_match@1`, INFERRED), so their `llm → tool` edges sit in
  `inf.agentdojo-positional_match-v1`.
- 624 converted executions (the PI-detector pipeline) also have `inf.agentdojo-pi_detector_sentinel-v1` and its
  union with the context bundle (EF E.10 item 13).
